# 货币与流通

泰拉没有已公开、可普遍使用的完整官方汇率表。`08_货币与准货币.csv` 将法币、国际结算、本地兑换物、代金券与纯玩法资源分开，避免把游戏 UI 的任何数值都当作居民货币。

## 可确定的结构

- 龙门币具有最强的跨地区结算证据，罗德岛贸易与多项玩法都使用它；这不证明所有国家都把它当唯一法币。
- 多个国家保有本地币种，历史国家还有已退出当代流通的货币。
- 汐斯塔等旅游/商业地存在多币接受证据，例如哥伦比亚金券、维多利亚磅。
- 多索雷斯的商业代币和约翰老妈代金券能在局部环境获得近似货币的流通性；后者甚至进入小型帮派交易。
- 赤金是可交付换取龙门币的精炼金条，也是游戏生产资源；不能直接把游戏内换算当作全泰拉固定汇率。
- 源石锭、合成玉、抽卡凭证、活动点数等应先判断是不是玩法资源，再决定能否进入世界内票面。
