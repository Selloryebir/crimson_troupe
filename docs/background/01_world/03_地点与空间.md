# 地点与空间

`04_地点名录.csv` 收录 149 项地点，并明确区分城市、移动城市、地区、建筑、舰船、遗迹与异常空间。名称字段优先保留三服直接写法，中文源缺口不再因英文页先被找到而误写成“中文不存在”。

## 已纠正的高价值条目

- 百灶 / Baizao / 百灶（バイザオ）：炎国首都。
- 圣骏堡 / Deity Grypherburg / サンクト・グリファーブルク：乌萨斯首都。
- 雅赛努斯 / Athenius / アテヌス：米诺斯首都。PRTS 词库还记录鹰角英文 `Athenus`；它是另一条直接出现的官方词形，不应用来抹去 `Athenius`。
- 西西里 / Sicilia：叙拉古城市或地区；“西西里夫人”等简中语境证明中文词形成立。
- 格兰法洛 / Gran Faro：伊比利亚聚落，不是“伊比利亚之眼”。
- 克莱布拉松 / Calais-Blason / セライブラソン：旧高卢边地，后归维多利亚；古堡与猩红剧团核心地点。
