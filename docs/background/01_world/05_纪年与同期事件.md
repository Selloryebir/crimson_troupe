# 泰拉纪年与同期事件

剧情年份、现实上线日期和档案更新时间是三条不同的轴。简中服先上线，国际服与日服后上线，不意味着同一事件在泰拉发生了三次。

## 与猩红剧团相连的锚点

| 泰拉时间 | 事件 | 关系 |
|---|---|---|
| 9 世纪以前，确年未明 | 拉特兰一位枢机受酒神影响，发动危及全城的宗教政变 | 证明酒神活动跨度很长，能介入宗教与政治 |
| 1019 | 高卢末代皇帝科西嘉一世加冕 | 旧高卢帝国审美与历史背景；同年哥伦比亚独立战争结束 |
| 11 世纪 20 年代 | 克莱布拉松古堡建成 | 后成为剧团舞台；建成时不能倒写成已经被剧团占据 |
| 1095 | 蓝卡坞片场演员劳拉坠亡，事故被压下并写入电影 | 《红丝绒》复仇与旧酒神介入的前史 |
| 1100 以前，确日未明 | 傀影回到克莱布拉松后失踪，罗德岛小队进入古堡并救回他 | 《傀影与猩红孤钻》主线结果 |
| 1100 | 蓝卡坞《红丝绒》事件；卢西恩击败旧酒神并继承其位置 | 旧团解散重组 |
| 1100 年初/秋 | 萨尔贡与米诺斯建交；雅赛努斯第一神殿重建、交换文物 | 同期文化交流与英雄戏剧背景，不与剧团强行建立因果 |
| 1100 年 9 月 | 莱塔尼亚女皇庆典与巫王高塔事件 | 同年莱塔尼亚处于重大事件中 |

完整记录见 `06_泰拉纪年.csv`；猩红剧团专题与世界事件的对应关系见 `../02_crimson_troupe/02_history/02_专题时间注释.csv`。事实事件只在通史表中维护一次，专题表以“泰拉时间 + 世界事件”作为自然定位字段。
