# 背景事实

本目录面向人工阅读，保存《明日方舟》世界观与猩红剧团相关的客观陈述、事实边界、官方专名和私有图像证据索引。网页文案建议、设计方案和技术实现不在此维护。

## 阅读顺序

1. `01_world/`：先建立泰拉的一般运行规则、国家、地点、纪年与货币边界。
2. `02_crimson_troupe/`：再读取猩红剧团组织、历史、IS2、《红丝绒》和藏品资料。
3. `03_terminology/`：查简中、英文、日文官方词形或资料转录词形。
4. `04_performance/`：查演出相关干员的事实依据。

## 维护边界

- Markdown 用于连续说明和人工入口；CSV 用于一行一个原子事实；第三方 PNG 原图只在仓库外由人工保管，仓库保存索引、来源与文字证据。
- 来源和审查状态随原子事实保存，不因归档位置改变而重写。
- 不确定、缺失或待核内容保留原标记，不以编辑推测补成事实。
- 创作建议见 `../content/`；网站实现见 `../blueprint/`；来源分级、待审事项与覆盖缺口见 `../planning/`。
