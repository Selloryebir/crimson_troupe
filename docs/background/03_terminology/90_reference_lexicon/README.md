# 参考词库

本目录保存覆盖面较广的三服词条转录，供人工检索和补全核心专名。它不是核心专名表的复制品：核心项目词形以 `../01_核心专名.csv` 为规范入口，本目录保留更广的参考覆盖。

| 文件 | 内容 |
|---|---|
| `01_泰拉词库.csv` | 572 条国家、地点、组织、种族、人物和事物综合词条 |
| `02_其他角色.csv` | 角色补充表 |
| `03_杂项词条.csv` | 其他专名补充表 |

旧“地理词条”“种族名录”“组织名录”均是 `01_泰拉词库.csv` 的字段筛选结果，不另设事实副本。

## 字段解释

- “鹰角中文、英文、其他语言”对应简中客户端或鹰角资料出现的词形。
- “Yostar 日文、英文”对应日服或国际服本地化词形。
- 空白表示当前词库未收录或该服尚无对应；`-` 表示不适用，两者不能混用。
- 词形记录不自动提供完整剧情语境；人物、地点或组织关系以相应主题事实表为准。

重要交叉例：词库直接支持百灶 / Baizao、圣骏堡 / Deity Grypherburg；雅赛努斯同时保留词库中的鹰角英文 `Athenus`、国际服 `Athenius` 和日服 `アテヌス`；克莱布拉松也存在 `Celaiblason` 与国际服 `Calais-Blason` 等不同官方拼写层，均按来源使用。
