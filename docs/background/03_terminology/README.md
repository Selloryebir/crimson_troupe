# 中英日专名

本目录用于规范拥有较完整官方信息或明确资料转录依据的简体中文、英文、日文专名，不承担界面语言切换和创意内容翻译。

| 文件或目录 | 用途 |
| --- | --- |
| `01_核心专名.csv` | 猩红剧团项目反复使用的核心人物、地点、组织和作品名 |
| `02_泰拉语言专名.csv` | 泰拉各语言或语域的中英日专名 |
| `90_reference_lexicon/` | 大规模参考词库、其他角色和杂项词条 |

字段为空表示尚未找到对应官方词形，不表示该语言中不存在该对象。编辑工作译与语域推拟见 `../../content/03_localization/`；运行时语言标签见 `../../blueprint/05_i18n/`。
