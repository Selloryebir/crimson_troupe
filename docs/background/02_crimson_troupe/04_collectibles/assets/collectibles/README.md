# 私有藏品素材挂载位置

本目录只定义人工本地挂载约定，不存放或分发第三方原图。

- 私有素材根位于仓库同级的 `../assets/`。
- 对应藏品原图由人工保存在 `../assets/collectibles/`。
- 需要本地查阅图鉴时，只能由人工把所需 PNG 放入本目录；PNG 已被 `.gitignore` 排除。
- agents、自动化脚本和网站构建不得访问私有素材根、复制原图、恢复本目录内容、使用 `git add -f` 或把原图放入任何产物。
- 仓库只维护 `01_藏品.csv` 中的文件名、相对路径、来源和文字说明。

机器相关的绝对路径不得写入仓库。删除本地挂载副本不会影响仓库外的人工备份。
