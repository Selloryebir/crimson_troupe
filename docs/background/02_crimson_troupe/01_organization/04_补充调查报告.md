# 补充调查报告 MLD-WW-035

《红丝绒》之后发布的泰拉记事社资料为猩红剧团补上了“现代调查机构怎样描述它”的视角。wiki.gg 收录的英文文本将文件归于梅兰德基金会特别委员会，编号 MLD-WW-035。

## 调查结论

- 剧团主要在维多利亚活动，也曾巡游莱塔尼亚、叙拉古和萨尔贡。
- 它曾在哥伦比亚偏远城镇引发事件，负责调查的人随后失踪。
- 对外形态像私人艺术家集体，依赖短期投资；成员技艺很高，但姓名缺失，影像中的面孔也难以辨认。
- 调查物证含带血气味的剧本、磨利菜刀、镣铐等，说明后台并非普通演出事故。
- 剧团盖章后从不取消合同；逃离者被追索，最终被迫完成“最后一幕”。
- 它会带走无家可归的儿童，逐步侵蚀自我与道德，使人变成剧团角色的化身。

这些条目把旧藏品中的合同、厨师、演员培养和逃离叙事互相印证：解约协议不是单纯笑话；今日菜谱的禁问来源与磨刀物证互相照应；“新芽”也不只是修辞。

## 卢西恩的附录立场

附录中的卢西恩把旧团所谓“起源”称为无数尝试之一。他拒绝让死亡成为唯一美学，重新提起丰收、仪式、歌声、葡萄和篝火等更古老的酒神意象，并宣称会书写新的起源。

这并不自动证明新剧团安全或善良，但明确区分了旧酒神的单一悲剧美学和卢西恩准备重写的方向。
