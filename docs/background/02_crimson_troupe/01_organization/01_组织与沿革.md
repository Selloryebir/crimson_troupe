# 组织与沿革

## 一句话定义

猩红剧团既是技艺精湛、历史漫长的云游艺术团体，也是旧酒神借“戏剧”侵入现实、挑选和塑造演员、制造真实悲剧的组织机制。

## 它为何首先像一个真实剧团

藏品和探索文件共同确认了大量具体岗位与制度：演员、导师、剧作家、报幕/喉舌、管家、仆从、道具师、厨师；帐篷、古堡舞台、暗道、密室、阁楼、仓库；票根、传单、合同与解约协议、化妆用品、香水、乐谱、唱片、舞鞋、首饰、菜单和排练物。地方月报甚至把剧团入驻描述成采风、刺激经济和创作新剧目。

这使剧团的恐怖成立：它不是一团没有行政结构的雾，而是能雇人、巡演、布置场地、训练儿童、管理道具、签署合同并经营公众形象的组织。

## 旧酒神如何越过舞台

No.187“酒神的印记”把来源追溯到饮酒、理性边界与艺术诞生的古老时刻。该存在喜好器乐、声带与肢体运动；当这些汇成戏剧，它以帐篷、演员和仆从开始小剧团。追求悲剧的欲望逐渐不满足于舞台表演，于是把生活与死亡本身当作可创作材料。

由此可解释几种组织行为：

- 在战争、天灾和感染者群体中挑选“新芽”。
- 让合同不可真正解除，把逃离者拖回“最终一幕”。
- 使演员的角色、自我与创伤逐渐难以分离。
- 把真实历史灾难写成剧作家手稿，再让剧本反过来影响现实。
- 把观众从观看者变成群演、证人、甚至悲剧材料。

## 五个时间层

1. 古老酒神：其名号/变体在千百年前已经出现，并曾影响拉特兰政治事件。
2. 高卢末期：克莱布拉松古堡建成；战争、征税、征兵和贵族覆灭为剧团提供场地与受害者。
3. 旧团时期：剧团占据古堡，训练卢西恩和暮落，让“猩红血钻”成为明星演员。
4. 古堡搜救：傀影受旧记忆召回，罗德岛进入古堡；主线后续采用“救回傀影”的结果。
5. 1100 年蓝卡坞：卢西恩在《红丝绒》事件中击败旧酒神、继承位置，旧团被解散重组。
