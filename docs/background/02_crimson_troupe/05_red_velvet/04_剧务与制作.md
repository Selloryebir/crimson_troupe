# 剧务与制作

## 旧剧团后台

旧团已有可证的道具、空间、合同、化妆、服装、音乐、餐食和演员管理：

- 道具师拥有完整工具箱；舞台机关足以让舞者擦身而过危险。
- 管家持万能钥匙，并调配城堡暗道、密室、阁楼和资源。
- 演员上场前使用香水缓和压力；珠宝、舞鞋、蝴蝶结和音乐盒构成化妆间/后台物证。
- 剧作家、报幕人和替补执行者之间存在岗位和审美冲突。
- 厨师每日变换菜式，团长禁止追问来源。
- 合同盖章后难以取消，解约和逃亡具有生命危险。

## 蓝卡坞片场补全的现代工种

《红丝绒》的家具、关卡和剧情提供了罕见的完整影视制作剖面：场景绘制、喷绘置景、道具花修复、服装羽毛/皮毛处理、替身与隐匿技艺、吊臂摄影机、实拍爆炸雨雪闪电、反光板、远程控物、收音屏障、监视器与逐帧检查、导演扩音、棚顶日月星光模拟。

逐项证据和用途见 `03_红丝绒片场与剧务.csv`。
