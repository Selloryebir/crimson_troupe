# 《傀影与猩红孤钻》

## 故事入口

罗德岛根据傀影最后的讯息追踪到维多利亚境内、原高卢边地克莱布拉松。傀影已失联数周；这里既是他的故乡，也是多场惨剧发生地。外勤小队在入夜后的雾林迷路，古堡成为唯一避难处，却不知道自己将被纳入一场宏大戏剧。

## 克莱布拉松怎样变成舞台

背景文件形成完整链条：

1. 102X 年，子爵为新建林地城堡发出高卢节庆请柬，节目含宴会、烟火与云游剧团。
2. 高卢准备战争、预征税赋并征兵；子爵把城堡变为最后防线。
3. 战败后，维多利亚草拟接收计划，但当地毁坏严重、经济凋敝。
4. 剧团从天灾与战争受害者中挑选“新芽”。地方月报却把艺术家进驻包装成采风与经济刺激。
5. 城堡原有暗道、密室、阁楼和物资；匿名成员要求管家补充陈设，称数月即可让主演登台。

这不是“剧团突然住进鬼屋”，而是战争遗址、地方衰退、文化宣传与组织掠夺共同形成的场地接管。

原子摘要见 `02_探索情报与背景文件.csv`。

## 探索机制与叙事信息

集成战略通过反复探索、随机节点、希望、源石锭、收藏品、剧目和幻觉，让玩家处在不稳定的古堡版本中。

- 希望：人员选择与成长的机会成本。
- 源石锭：探索内部经济，不等于泰拉通用法币。
- 收藏品：物件既改变规则，也留下人物、国家和舞台制度的证据。
- 剧目：普通版提供收益；猩红版让同一故事显露代价、不确定或反转。
- 幻觉：改变地图可见性、路径、资源和敌我状态，证明探索者的认知不是稳定镜头。
- 过往演出：把事件图、结局图和历史/艺术寓言装进剧团策展体系。

## 幻觉报告册

基础幻觉包括迷茫、盲目、暴怒、孤独、偏执、敏感、臆想、生存和谨慎；高难追加狂乱、焦虑、痴愚、颓废；正式调查 11+ 还会把特定两种幻觉融合成慎敏症、迷执症、慎想症、怒想症、偏敏症、怒盲症与慎存症。

它们不是纯 UI 滤镜：有的延长地图，有的遮蔽远端节点，有的让本层财富无法带走，有的改变招募与部署，有的令藏品被替换。详细效果见 `03_幻觉报告册.csv`。

## 活页剧目

13 个剧目都有普通版和猩红版：普通版提供收益，猩红版则加入先失后得、触碰损伤、价格波动、收益抵押或不确定返还。完整三服标题、故事引和玩法效果见 `04_活页剧目.csv`。

## 过往演出与四个结局

41 项过往演出含 2 张首页、35 张事件和 4 张结局图。它们把高卢遗物、舞会、童话、丧葬、商业、写作、评论、偶人和真实悲剧纳入剧团的策展语言。逐项中英标题和摘要见 `06_过往演出展览.csv`。

四个结局在三服的正式标题不必直译一致：

- 舞会终场 / Crimson Finale / 舞曲の終わり：罗德岛救回傀影，作为后续采用的主线结果。
- 滑稽喜剧 / Ridiculous Comedy / 奇妙な滑稽劇：黑冠与偶人路线。
- 盛大揭幕 / Grand Opening / 盛大なる開幕：宣称剧团因傀影而重生。
- 沉默之章 / Silent Chapter / 声なき楽章：剧作家的稿件覆盖现实。
