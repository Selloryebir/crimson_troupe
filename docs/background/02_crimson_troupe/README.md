# 猩红剧团事实

本目录按组织、历史、IS2 资料、藏品与《红丝绒》五个连续主题组织。

英文机构主名为 **Crimson Troupe**。

| 目录 | 主要内容 |
| --- | --- |
| `01_organization/` | 组织沿革、人物、关系和补充调查报告 |
| `02_history/` | 通史事件与剧团专题之间的自然字段关联 |
| `03_phantom_and_crimson_solitaire/` | 《傀影与猩红孤钻》的探索、幻觉、剧目、结局、演出与音频资料 |
| `04_collectibles/` | 藏品原子表、纯文本图鉴和公开来源索引 |
| `05_red_velvet/` | 《红丝绒》事件、关卡、片场工种与剧务资料 |

事件事实只维护在 `../01_world/06_泰拉纪年.csv`，专题时间表通过“泰拉时间 + 世界事件”定位对应记录，并只补充与剧团的关系。藏品事实、公开来源与审查状态只维护在 `04_collectibles/01_藏品.csv`；`04_collectibles/02_藏品图鉴.md` 是不依赖图片的纯文本阅读视图，并单独说明 No.029 英文名称的来源依据。

多结局、服务器上线时间和官方中英日标题保持各自事实层级，不合并成单一事件或自行直译。专题页面口径和内容应用见 `../../content/02_crimson_troupe/`。

## 数据边界

- `04_collectibles/01_藏品.csv` 是 51 件高相关藏品选集，不是 IS2 全藏品表。
- 活页剧目共 13 份，过往演出共 41 项；数量与逐项资料以对应 CSV 为准。
- 过往演出的中文和英文有直接转录；日文逐项标题尚未完成可靠定位，故保留空缺而不直译。
- 活页剧目并列三服标题与普通、猩红规则；标题差异不做归一化。
- 《红丝绒》发生在后续时期，旧古堡剧团、旧酒神、新酒神和新剧团不能视为同一时段的组织状态。
- 官网专题页与游戏内图标存在资产差异。No.029 的英文主名判断采用实际游戏图像与国际服本地化的共同证据。
