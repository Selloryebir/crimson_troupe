# 语言学与翻译说明

## 推拟流程

1. 收集简中、国际服、日服客户端直接词形。
2. 确定现实代理语言与文字系统；若国家明显多语，先拆语域。
3. 专名优先保留词干，再按目标语言音系和正字法适配；有明确语义动机才翻译。
4. 语言自称仿 MediaWiki：短、可识别、使用本语言文字；说明文再补“语言”一词。
5. 给出主要候选、备选、近似发音和证据等级。没有足够材料时保留多个方案。

## 高可信度构词

- 叙拉古语 `Siracusano`：官方活动名 `Il Siracusano` 直接支持词干与阳性名词化；说明文可写 `lingua siracusana`。
- 卡西米尔语 `Kazimierski`：仿波兰语自称 `Polski`；完整形式 `język kazimierski`，文学性系统名可候选 `kazimierszczyzna`。
- 莱塔尼亚语 `Leithanisch`：按德语 `Leithanien + -isch`；完整形式 `Leithanische Sprache`。
- 乌萨斯语 `Урсусский`：按俄语形容词构词；完整形式 `урсусский язык`。
- 米诺斯语 `Μινωικά`：仿现代希腊语语言标签的中性复数；说明文 `η μινωική γλώσσα`。
- 龙门话 `龍門話`：比“龍門語”更像粤语型地区自称；可写 `炎文（龍門話）` 显示母语域。
- 塔拉语 `Tengae`：已有世界内直接词形，优先于重新生成的现实爱尔兰语对应。

## 多解区域

- 拉特兰：`Lateranensis` 偏教会拉丁，`Laterano` 偏世界语式现代国际机构，`Laterana` 更直观；三者是网站语体方案，不是假称三种官译。
- 谢拉格：`Kjeragisk` 偏挪威语构词，`Kjeragisch` 偏阿勒曼尼/德语构词；可按地区页面使用。
- 伊比利亚：西语型 `Iberiano` 与葡语型 `Iberiano ocidental` 需加语体限定，避免选择器重名。
- 卡兹戴尔：`Kazdelian` 最稳；希伯来字母或阿拉伯字母候选只适合受控专题，不能冒充统一标准语。
- 萨尔贡：应保留阿拉伯语型 `لغات سارغون` 与波斯语型 `زبان‌های سارگون` 等多个入口，不造“全国唯一语”。
- 萨米：`Sámegiella` 只能作总入口式识别，正式内容还需细分具体萨米语言。
- 杜林：`Durinera` 借巴斯克语 `-era` 构语言名，但材料仅支持部分地名风格。
- 阿戈尔：`Ægirian` 有国际服词形；拉丁式 `Lingua Aegiriana` 是礼仪化扩展，不证明阿戈尔语等于拉丁语。
- 汐斯塔：`Kreyòl Siesta`、`Criollo siestano`、`Crioulo siestano` 可代表不同社群语体，不必争夺单一官名。

## 发音原则

IPA 只描述“按现实代理语言读时的近似”，不是官方配音规范。专名出现多个官方拼写时分别记录：例如雅赛努斯有 `Athenius` 和 PRTS 词库所录鹰角英文 `Athenus`，两者都应保留来源，不用一个倒推另一个为错误。

## 外名矩阵怎么读

矩阵单元 `k_ij` 表示“以泰拉语言语境 `k_i` 书写国家或语言 `k_j`”。若该格有三服直接词形，优先官方；若只有现实代理语言可推，则按本节流程生成；若目标语本身材料不足，则标待审。矩阵用于票面、海报、导航和短句，不应被训练成声称完整的虚构语言语法。
