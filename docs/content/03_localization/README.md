# 内容本地化与泰拉语域

本目录保存工作译、语言学推拟和创意内容的多语方案，不将其表述为官方译名。

| 文件 | 内容 |
| --- | --- |
| `01_泰拉语域方案.csv` | 现实语言参照、显示标签、备选词形与构词依据 |
| `02_地点中文工作译.csv` | 官方中文缺失时的编辑工作译 |
| `03_语言槽位.csv` | 跨语言矩阵的 25 个源、目标槽位 |
| `04_专名方案.csv` | 以“目标类别”区分国家名与语言名的两组 25×25 长表 |
| `05_审核队列.csv` | 原工作簿中的待人工审核项 |
| `06_语言学与翻译说明.md` | 构词、发音和矩阵使用原则 |

官方中英日专名见 `../../background/03_terminology/`。运行时语言标签、回退和旧标签映射见 `../../blueprint/05_i18n/`。

## 两个独立维度

- 页面语言：简体中文、English、日本語，决定正文使用哪一服本地化或工作译。
- 泰拉语域：Siracusano、Leithanisch、Урсусский 等，决定海报、票面、城市外名、短句和视觉语体。

用户可以阅读简中正文，同时查看以叙拉古语拟写的票面；不能把泰拉语域表述成已经完成的官方全文翻译。

```text
页面语言：简体中文
泰拉语域：Siracusano · 叙拉古语

[简体中文] [English] [日本語]
[Siracusano] [Leithanisch] [Урсусский] [……]
```

`04_专名方案.csv` 的“原填充色”字段保留来源材料中的分类线索：绿色为中英日客户端或官方词形，蓝色为 AI 工作译或受控转写，黄色为语言学推拟，灰色为材料弱、需人工复核。该字段只用于回溯，内容性质与审核状态必须以文字表达，不能只依赖颜色。
