# 内容本地化与泰拉语域

本目录保存工作译、语言学推拟和创意内容的多语方案，不将其表述为官方译名。

| 文件 | 内容 |
| --- | --- |
| `01_泰拉语域方案.csv` | 现实语言参照、研究用短标签、备选词形与构词依据 |
| `02_地点中文工作译.csv` | 官方中文缺失时的编辑工作译 |
| `03_语言槽位.csv` | 跨语言矩阵的 25 个研究槽位与候选标识 |
| `04_专名方案.csv` | 以“目标类别”区分国家名与语言名的两组 25×25 长表 |
| `05_审核队列.csv` | 原工作簿中的待人工审核项 |
| `06_语言学与翻译说明.md` | 构词、发音和矩阵使用原则 |

官方中英日专名见 `../../background/03_terminology/`。运行时地域配置、现实语言标签、回退和路由见 `../../blueprint/05_i18n/`。

## 研究资料与运行时配置的边界

- 本目录研究泰拉语言身份、现实语言参照、工作译和构词方法，不直接定义网页路由或选择器。
- 网站只为人工批准的国家实体建立一个地域展示配置，同时绑定现实文本语言、世界内语言身份、URL、货币和回退关系。
- 普通页面不能分别选择“页面语言”和“泰拉语域”；更换地域配置时，上述内容作为一个整体切换。

证据或编辑预览可以并列比较中英日官方字段、工作译和语言学推拟；普通页面只显示当前地域配置的正文与专名。不能把现实代理语言或工作译表述成已经完成的官方全文翻译。

本目录列出的是创作候选与审核材料，不构成网页实现清单。运行时只实施 `../../blueprint/05_i18n/01_locales.yaml` 中的十个地域配置；未获批准的候选项不得自动进入选择器、路由或货币映射。

购票界面词另受启用门约束。每个地域配置挂载购票模块前，需要检索并人工审核相应现实语言与文化中的演出购票网站常用词汇；审核结果随正式消息或内容资源维护，不把“票篮”等中文简称机械翻译，也不把内部 `purchase_flow`、Outcome ID 或 URL 当作显示词。当前阶段不为尚未进入内容准备的地域配置建立空词表或虚构译文。

```text
当前地域配置：叙拉古
页面文本：Italiano
世界内身份：Siracusano · 叙拉古语
当地币种：弗洛林

[炎国] [东国] [维多利亚] [哥伦比亚] [叙拉古] [……]
```

`04_专名方案.csv` 的“原填充色”字段保留来源材料中的分类线索：绿色为中英日客户端或官方词形，蓝色为 AI 工作译或受控转写，黄色为语言学推拟，灰色为材料弱、需人工复核。该字段只用于回溯，内容性质与审核状态必须以文字表达，不能只依赖颜色。
