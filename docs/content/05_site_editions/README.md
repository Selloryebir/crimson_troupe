# 网站版本与内容集契约

本目录只定义表网站、历史网站快照和内容集之间的稳定边界，不保存 M0 示例记录，也不预先生成 M3 页面内容。

## 三类时间线

| 层级 | 唯一职责 | 网站构建 |
| --- | --- | --- |
| `docs/background` | 可追溯事实、来源、服务器与版本记录 | 禁止直接读取 |
| 表网站公开时间线 | 新酒神剧团对外发布的机构叙述 | 从经审核的 `docs/content` 内容集读取 |
| 里网站历史时间线 | 旧酒神历史网站快照中的独立叙述 | M3 从独立内容集读取 |

表里网站可以对同一背景事件给出互相冲突的日期、人物状态、新闻标题或解释。冲突属于创作设计；两边分别保存展示记录，以稳定的事实自然定位字段或创作关联标识建立关系，不覆盖 background，也不把任一网站叙述反写成事实。

## 内容集选择

一次构建只选择一个明确的内容集。内容集至少声明：

- `contentSetId`：内容集标识；
- `siteEditionId`：稳定的网站版本标识，例如 `new-dionysus`；
- `localeProfileId`：地域展示配置；
- `snapshotTerraDate`：历史快照的泰拉日期；非历史网站留空；
- `distortionSaturationAt`：历史快照的异常饱和阈值，限 5～8；非历史网站留空；
- 页面、路由、搜索与可用模块清单；
- 人工审核状态和来源关联。

`siteEditionId` 用于内部关联和搜索，不随日期修订。历史快照 URL 使用人工确认的泰拉日期；未确认时蓝图和受限预览统一使用 `0000`，正式 M3 发布不得继续使用该占位值。

## 表里网站独立实现

表网站和里网站不建立页面、路由、记录数量或功能的一一对应约束。

- 表网站可以有三个新闻页，里网站可以有五个或没有对应页面。
- 表网站在购票模块安装后可以处理未来场次的世界观购票；里网站只展示过去演出，不挂载预约、购票或观演凭据流程。
- 表网站使用现代、可信的剧团视觉；里网站可以使用涂黑、划改、撤回、异常图片和 creepypasta 类表现。
- 两者只复用已经证明语义一致的底层工具和组件，不为复用强行共用页面模板。

M0 只实现表网站。M3 的里网站使用独立路由清单、内容集、设计 token、页面组件和搜索索引；M0 不预建其页面或异常状态机。

## URL 与入口

表网站继续使用 `/:profile/*`。历史网站快照使用：

```text
/:profile/archive/site/:terraDate/*
```

在日期待审阶段使用 `/yan/archive/site/0000/` 作为蓝图示例。日期后的路径完全由里网站定义，不要求镜像表网站。

M3 安装前，表网站页脚版本戳只是普通版本信息，不生成无功能入口。M3 安装后，桌面页脚右下区域和移动端页脚文档流末尾的版本戳提供低显著度入口；里网站显示明确的捕获日期和“返回当前网站”。隐藏的是发现过程，不是访问权限，直接 URL、刷新、书签和浏览器后退均须可用。

## 单次访问异常进度

里网站初始就可以包含少量不可信信息、矛盾新闻或异常演出记录。这些是经人工编写和审核的里网站内容记录，属于历史快照的基线；它们不改写 background，也不由运行时随机生成。

| 有效探索数 | 呈现层级 |
| --- | --- |
| 0 | 可信的旧网站基线，只保留内容集中预置的少量冲突 |
| 1～2 | 低强度扭曲、涂抹或异常表现 |
| 3～饱和阈值前 | 逐步增强冲突、划改和异常呈现 |
| 饱和阈值及以后 | 维持固定的最高异常层级，不继续累加 |

每个历史快照声明一个确定的饱和阈值。首个快照默认为 6，人工只能在 5～8 范围内调整；同一快照每次进入都使用同一阈值，不随机选取。

历史网站初始落地只建立访问状态，不计为探索。随后只有以下操作累加进度：

- 首次成功进入一个新的里网站页面；
- 首次成功打开一个关键档案或内容项。

可计数目标必须提供稳定的 `interactionKey`，每个键在本次访问内只计一次。滚动、菜单开合、重复点击、失败重试、开关稳定演出版和返回操作不计数。

进度只存活于当前页签对同一历史快照的本次访问。同一快照内部的前进或后退保留进度；离开当前 `/:profile/archive/site/:terraDate/*` 快照路由域、切换 `terraDate`、刷新、重新进入、直接打开、新建标签页或从表网站经浏览器前进或后退进入，都从基线开始。进度不写入 `localStorage`、`IndexedDB`、Cookie、URL 或服务器。

稳定演出版隐藏渐进的扭曲、涂抹、动效和其他污染呈现，并暂停有效探索计数；启用期间的操作不消耗 `interactionKey`。它不删除已审核的基线内容，也不重置本次访问进度。关闭稳定模式后从同一层级继续。

运行时异常只是呈现叠加层，不改写内容记录、路由、搜索索引或 SEO 输出。基线中经审核的冲突记录可以按里网站搜索规则进入其独立索引；随点击出现的呈现差异不进入索引。项目不保存“已发现快照”状态，重访依靠页脚版本戳、浏览器历史或书签。

## 搜索隔离

索引键固定为 `localeProfileId + siteEditionId`。查询、结果、摘要、纠错和无结果提示都只能使用当前组合获准公开的内容。

- 不跨地域配置、现实语言或网站版本搜索；
- 表网站不泄露里网站的旧新闻、旧称和人物状态；
- 里网站不自动替换为表网站后来修订的文案；
- background 不进入公开索引；
- 某个网站版本没有对应地域配置时，不生成该组合索引。

M0 只生成 `yan + new-dionysus`。跨语言或跨版本比较只能由用户主动进入证据、档案或编辑预览后进行。
