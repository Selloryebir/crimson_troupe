# 音乐、乐器与演出干员

`../../background/04_performance/01_干员事实.csv` 只记录剧情、档案、模组、家具或游戏文本中出现的能力与经历；`02_剧团岗位推演.csv` 才是“如果加入猩红剧团，可能做什么”的编辑建议。角色拥有现实发行的 EP，不自动证明角色在泰拉会演奏。

## 核心阵容逻辑

| 工作面 | 代表人选 | 合理岗位 | 依据边界 |
|---|---|---|---|
| 作曲、指挥、学院音乐 | 车尔尼、黑键 | 驻团作曲、室内乐统筹、排练指导 | 以档案/剧情的音乐训练为准 |
| 弦乐与意识型音乐 | 黑键、塑心、阿米娅 | 大提琴、先锋独奏、室内乐 | 塑心的技艺有精神风险；阿米娅熟练度不夸大 |
| 管乐与地方戏曲 | 止颂、小满、晓歌 | 大号、竹笛、戏曲伴奏、排练乐手 | 保留具体地区与传统，不揉成“民族音乐” |
| 歌唱与叙事 | 空、空弦、聆音、埃拉托、斯卡蒂、爱丽丝 | 主唱、合唱、吟游叙事、儿童日场 | 区分职业歌手、文化传承与偶尔演唱 |
| 戏剧表演 | 傀影、暮落、酒神 | 主演、性格演员、叙事对抗者 | 不能把创伤与胁迫包装成自愿回归 |
| 编舞与仪式 | 月禾、歌蕾蒂娅、逻各斯 | 动作训练、阿戈尔表演顾问、语音/仪式指导 | 神圣/仪式性内容不能只当舞美装饰 |
| 影视与记录 | 年、稀音、卡达、蒂比、食铁兽 | 导演、摄影、花絮、绘景、特技 | 影视经验不自动等于舞台表演能力 |
| 造型与文本 | 罗比菈塔、裁度、梓兰、海蒂 | 化妆、服装、场刊、对白整理 | “剧作家”等称谓若是推演必须标明 |

## 两类常见误判

- 专属吉他家具能证明乐器关联或所有权，不一定证明熟练度。红豆另有通讯记录中实际弹奏吉他的文本，证据更强。
- 骋风档案涉及受其资助的小提琴手，不等于骋风本人会拉小提琴；他更适合赞助、安保或听众位置。

推演字段含事实依据、岗位建议、把握与注意事项；实现时可过滤“高把握”，再把中低把握放入策划备选。
