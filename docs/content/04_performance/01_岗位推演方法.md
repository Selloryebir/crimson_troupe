# 剧团岗位推演方法

岗位建议不是角色事实。每个候选按四步判断：

1. 直接技能：档案是否明确写出演奏、歌唱、表演、作曲、导演、摄影、服装或舞台经验。
2. 可迁移能力：战斗/技艺能力能否安全转为动作指导、特效、灯光、收音或舞台机械。
3. 意愿与伦理：角色是否可能自愿参与；是否会因创伤、信仰、政治或技艺风险拒绝。
4. 制作需求：岗位是否在旧团藏品、《红丝绒》片场或泰拉演出产业中有现实位置。

输出的“推演把握”只衡量岗位推演合理性，不是角色能力强弱。事实依据与边界通过“中文”字段关联 `../../background/04_performance/01_干员事实.csv`；涉及意识影响、感染风险、文化神圣性或旧团创伤时，必须同时读取事实边界。
