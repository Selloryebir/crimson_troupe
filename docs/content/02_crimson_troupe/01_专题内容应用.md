# 猩红剧团专题内容应用

本文件收录由猩红剧团背景事实推导出的页面口径、叙事结构和创作边界。事实依据以 `../../background/02_crimson_troupe/` 为唯一来源；本文件不新增世界观事实。

## 组织阶段与页面版本

网站必须选择或明确切换时间层。最有力的做法不是把全部角色列成“现任员工”，而是让公开官网、古堡缓存、罗德岛调查档案和新酒神改稿同时存在，各自有日期与权限。

蓝图若采用事件后官网，应把“新起源仍未完成”作为内容状态，而不是直接宣布一切已经净化。

## 档案快照

| 快照 | 公开页面口径 | 隐藏层 |
|---|---|---|
| 高卢节庆 | 新古堡、宴会、烟火、云游演出 | 战争征税、征兵与贵族末日 |
| 维多利亚接管 | 艺术家采风、地方经济重建 | 剧团挑选灾民、接管密室 |
| 古堡搜救 | 暂无正常营业，仅存缓存 | 傀影回归、四结局与幻觉 |
| 蓝卡坞片场 | 电影项目、剧组通告、试映 | 旧酒神进入片场并重演悲剧 |
| 新酒神之后 | 解散重组、书写新起源 | 继承的力量是否仍会复制旧团 |

每个页面最少记录 `泰拉时间`、`档案版本`、`当前组织阶段` 和 `剧透范围`。

## 古堡入口与探索机制

这段引言为“居民搜到的官网”提供了可靠层级：公开搜索结果可以正常；古堡缓存则以“推开大门”为会话起点；罗德岛镜像以搜救档案重构同一站点。

重要的不是把所有机制照搬成网站数值，而是理解它们的叙事作用。网站借用时必须保留稳定导航、关闭异常、降低动效和关闭声音的现实控制权。

这组数据尤其适合内容设计：同一剧目可有“公开节目单”和“执行批注”两个面，但不能将猩红规则用于真实付款、真实倒计时或阻止退出。

网站可以收集多结局，但事实层必须指出哪一条被后续剧情采用，不能把游戏分支全部写成同时发生。

## 蓝卡坞片场专题

因此官网可以把片场专题做成生产文档，而非只做剧情摘要：通告单、工钱结清、部门解散、道具清单、镜头记录、试映、致观众信和事故复盘都能直接获得世界观依据。

页面音频应默认静音，并将“剧情中有精神影响”与现实网页音频的无障碍控制严格分开。

## 制作与观演安全

现实片场安全仍然必要，但泰拉还需增加：

- 源石技艺施术人、作用范围、失控处理与医疗观察。
- 感染者隐私、防护与不歧视入场/用工。
- 移动地块和天灾预警造成的撤离窗口。
- 意识/情绪类技艺的知情同意和无影响观看版本。
- 伪装、隐匿与远程控物道具的可见标识，避免后台误入。
- 古堡物件在归属前先进行危险性确认，遵守罗德岛外勤报告逻辑。

这些字段既能让世界可信，也能为官网的“观演提示”“技术说明”“幕后日志”和事故档案提供内容。
