# 世界观内容应用

本文件收录由背景事实推导出的创作建议、编辑边界和页面内容口径。事实依据以 `../../background/01_world/` 为唯一来源；本文件不新增世界观事实。

## 移动城市、天灾与巡演

因此巡演不是在静态地图上连点：地址可能随城体移动，场次会因天灾信使警报整体延期，物流还要穿越荒地与检查站。

适合网站的数据字段是“城市/地块、当季停靠区、最后确认时间、天灾状态”，不是伪造经纬度。

## 矿石病与感染者

对剧团创作而言：感染状态不应作为公开报名字段；场馆需有防护与医疗流程；猩红剧团把感染、痛苦和死亡纳入演出是恐怖核心，不能只当华丽装饰。

## 源石技艺与观演说明

节目资料应区分：实物舞台技术、由技艺生成的效果、会影响观众意识的效果、纯宣传性修辞。每个会作用于观众的技艺都应有安全距离、停演机制和替代观演方案。

## 地区技术与媒体语法

- 哥伦比亚、龙门、汐斯塔、卡西米尔适合商业媒体、广告、直播或现代票务语法。
- 莱塔尼亚适合学院、宫廷、音乐厅和技艺设备。
- 萨尔贡、萨米、卡兹戴尔及边远地区必须按具体地点决定网络与结算条件。
- 阿戈尔某些技术远超地表，但不等于能接入地表公共网络。

## 站点在世界内的通信模型

合理的网站模型是大城市与移动城内网正常访问，跨城由运营商或缓存节点同步，荒地只收到低带宽文字、延迟节目单或离线票据；不同国家还可能审查或保留本地镜像。

这会自然产生多版本叙事：同一公告在龙门、莱塔尼亚和乌萨斯镜像中措辞不同，旧古堡缓存又保留更早页面。版本差异应记录来源和时间，不必一律解释成“网页故障”。

## 人员资料与演出产业

公开人员资料应分列，感染状态保持私密。

因此官网可以合理出现：审查批文、赞助、巡演承运、纸票和终端票、电影首映、宗教仪式节目、乡村戏班与商业直播。

## 深层宇宙论与剧透

它们能解释世界为何如此，却不应吞没猩红剧团的艺术、控制、感染与个人创伤。默认官网仅以隐秘档案或错误页含蓄触及，并按服务器进度控制剧透。

## 地点的内容用法

| 类型 | 地址与巡演逻辑 |
| --- | --- |
| 固定城市 | 可写行政区和场馆；没有证据时不伪造街道号 |
| 移动城市 | 写当季地块、航线、停靠窗口和最后确认时间 |
| 战乱/政变城市 | 场次进入延期、取消、仅档案或等待复核状态 |
| 历史国家/废弃城市 | 仅作旧票根、复排、遗物展和档案，不列当前普通场次 |
| 舰船/陆行舰 | 地址使用航线、靠泊与通信窗口 |
| 古堡/梦境/异常空间 | 标为“非稳定物理地点”，只存在于深层叙事 |

对猩红剧团最有用的地点群：

- 高卢遗产：克莱布拉松、古堡、被维多利亚接收的高卢旧地。
- 音乐制度：崔林特尔梅、维谢海姆、莱塔尼亚学院与高塔。
- 英雄戏剧：雅赛努斯、第一神殿、米诺斯城邦公共空间。
- 商业演出：龙门、汐斯塔、多索雷斯、卡瓦莱利亚基。
- 电影工业：哥伦比亚蓝卡坞/Wrankwood 与《红丝绒》片场。
- 政治与家族：蒙特卢佩、沃尔西尼、西西里及叙拉古地方城市。

蓝图库只能从名录选取地点并附具体年代；不得把这些地点默认成同一时刻均可巡演。

## 时间快照

- 旧高卢：帝国礼仪、里弗尔、贵族邀请函和古堡初建。
- 维多利亚接管后的克莱布拉松：地址与行政措辞改变，旧高卢记忆仍残留。
- IS2 古堡搜救：剧团仍以旧酒神和古堡机制运作。
- 1100 年《红丝绒》：蓝卡坞片场、电影工业、新旧酒神对峙。
- 事件之后：旧网页作为缓存，新酒神可重写组织声明。

同年事件只提供“世界同时在运转”的感觉；没有剧情连接时不要写成酒神策划的结果。

- 旧高卢票根与请柬可使用高卢制度和历史货币；维多利亚接管后地址、行政称呼和通行文件应改变。
- 1100 年蓝卡坞《红丝绒》事件后，旧团解散重组，官网的组织口径发生断裂。
- 1100 年莱塔尼亚发生女皇庆典与巫王高塔事件，当地巡演不能默认稳定营业。
- 同年米诺斯—萨尔贡建交、雅赛努斯重建神殿，可作为世界新闻或客座文化项目，但不写成剧团策划。
- 国际服/日服上线晚于简中服是现实发行时间差；官网的泰拉年份不随服务器发布日期变化。

## 票务与货币

| 场景 | 建议 |
| --- | --- |
| 龙门或跨国预售 | 显示龙门币结算，并说明只是结算币种 |
| 叙拉古、莱塔尼亚、卡西米尔本地场 | 显示当地币；无汇率时不自动换算 |
| 汐斯塔、多索雷斯 | 可列已知接受币种或本地代币，附场馆规则 |
| 卡兹戴尔、萨米、偏远萨尔贡 | 由具体地点和时代决定，可用物资、外币或窗口凭证 |
| 高卢历史复排 | 里弗尔仅作历史票根视觉，不进入当代默认结算 |
| 票篮小游戏 | 可用龙门币、源石锭等叙事数值，但必须保持虚构且不接支付 |

当汇率没有证据时，正确内容是“请至剧院窗口确认”，而不是套现实汇率。
