# 国家、文化与语言

泰拉国家不是现实国家的替换密码。较可靠的做法是识别“文化编码”：命名、建筑、法律、宗教、服饰、音乐、政治制度和历史母题可能来自一个或多个现实地区；虚构国家仍有自己的历史与族群结构。

## 语言不是一国一语

玻利瓦尔、萨尔贡、萨米、伊比利亚、汐斯塔、维多利亚等都有多语、历史语言或移民语体。龙门话更适合视为炎语体系内的粤语型都会变体；雷姆必拓可先按维多利亚语区域语体处理；萨尔贡与萨米的总标签应继续下钻，而不是伪造全国唯一标准语。

三种层次必须分开：

- 玩家界面语言：简体中文、English、日本語。
- 泰拉世界内语言：叙拉古语、莱塔尼亚语、乌萨斯语等。
- 网站拟写语体：用现实代理语言为尚无官方文本的页面生成受控词形。

拟写方法、语域标签和两个 25×25 矩阵见 `../03_localization/README.md`。官方中英日语言专名见 `../../background/03_terminology/02_泰拉语言专名.csv`。
