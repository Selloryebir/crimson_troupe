# 购票体验契约

本文件是表网站世界观购票体验的唯一详细契约。决策清单记录人工结论，模块 YAML 声明边界，旅程和功能目录只描述任务；价格公式、结局标识、导演约束、本地状态和组合印章不得在其他文件中另建一套定义。

## 范围与命名

- 体验只模拟“在泰拉订票会看到什么、经历什么”，不产生现实交易、订单、凭证、权益或服务关系。
- 内部模块使用稳定标识 `purchase_flow`；面向用户的购票入口名称来自当前地域配置的消息资源，不把“票篮”固定为跨语言产品名称。
- 每次流程绑定一个 `performanceId`，使用 `/:profile/purchase/:performanceId`。用户如需查看其他演出，应退出并回到演出日历或详情；流程内不提供换场、改签、退款或多场次暂存。
- “购票成功”和“购票失败”只表示世界观互动结果。成功后生成的正式展示物统一称为“观演凭据”，并说明不可入场、不可兑付且无现实价值。
- 黄牛平台是购票失败后的唯一小游戏分支。已取消的三幕审票、候补席点名和天灾改签不属于本体验。

## 基础流程

1. 用户从具体演出进入购票页，在完整分区图中选择 S/A/B/C/D/包厢等分区。
2. 页面显示该演出和分区的固定 LMD 基准价，以及当前地域配置绑定币种的对应演示价。
3. 用户点击当前语言中的购票主操作。
4. 首次结果可以是叙事网络波动、正常渠道成功，或正常渠道失败并进入黄牛邀请。
5. 用户可以直接接受黄牛报价，或拒绝后收到一次 2% 挽留优惠。
6. 再次拒绝形成拒绝黄牛结局；接受原价或优惠报价后分别产生抢票成功或失败结局。
7. 结果页显示本轮结果、模拟费用和可用下一步；成功结果可以继续生成观演凭据，失败结果不提供可下载凭据。

正常渠道失败只是进入黄牛邀请的流程节点，不是独立成就或第八个结局。

## 价格规则

每个演出和分区的 `basePriceLmd` 由内容人员固定填写。比例使用整数基点配置，`10000` 表示 100%；金额在内部使用整数最小单位，并在最终显示时按对应币种规则舍入。

首版默认参数如下，正式内容可以在人工审核后调整：

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `markupRateBps` | 15000 | 黄牛在基准价上加价 150% |
| `serviceFeeRateBps` | 2500 | 按当前黄牛报价收取 25% 手续费 |
| `retentionDiscountRateBps` | 200 | 拒绝后的一次性 2% 挽留优惠 |

计算顺序固定为：

```text
原价黄牛报价 = 基准价 × (10000 + markupRateBps) / 10000
优惠黄牛报价 = 原价黄牛报价 × (10000 - retentionDiscountRateBps) / 10000
手续费 = 当前黄牛报价 × serviceFeeRateBps / 10000
成功显示总额 = 当前黄牛报价 + 手续费
黄牛抢票失败显示费用 = 手续费
```

- 正常渠道成功显示基准价，不应用黄牛加价和手续费。
- 叙事网络波动和拒绝黄牛不产生模拟费用；只有已经接受原价或优惠黄牛报价的失败结果显示对应手续费。
- 所有金额同时显示 LMD 与当前地域配置绑定的世界内币种；换算只使用人工硬编码汇率。
- 汇率缺失时按既有 i18n 契约使用明确标记的 1:1 演示值，不将其写入背景事实。
- 页面不得建立余额、实际扣款、支付接口、商户号或现实交易记录。

## 结局与成就

内部 ID 稳定且不翻译；名称和收集文案从当前地域配置的内容资源读取。下表只固定触发和能力，不把讨论中的戏谑文案视为正式文案。

| Outcome ID | 触发条件 | 是否购到票 | 模拟费用 | 可否继续探索 |
| --- | --- | --- | --- | --- |
| `ENDING_NETWORK_ERROR` | 购票操作出现叙事网络波动 | 否 | 无 | 是 |
| `ENDING_NORMAL_SUCCESS` | 正常渠道直接成功 | 是 | 基准价 | 本轮结束，可再次尝试 |
| `ENDING_REJECT_RESCALPER` | 拒绝黄牛，再拒绝一次性优惠 | 否 | 无 | 是 |
| `ENDING_SCALPER_SUCCESS` | 接受原价黄牛报价并成功 | 是 | 原价黄牛报价＋手续费 | 本轮结束，可再次尝试 |
| `ENDING_SCALPER_FAILED` | 接受原价黄牛报价但失败 | 否 | 原价黄牛报价对应手续费 | 是 |
| `ENDING_DISCOUNT_SUCCESS` | 接受优惠黄牛报价并成功 | 是 | 优惠黄牛报价＋手续费 | 本轮结束，可再次尝试 |
| `ENDING_DISCOUNT_FAILED` | 接受优惠黄牛报价但失败 | 否 | 优惠黄牛报价对应手续费 | 是 |

黄牛分支共有 5 个结局，完整流程共有 7 个结局。每个 Outcome ID 同时对应一个唯一成就；重复结果不重复增加成就或印章图层。

## 自适应结局导演

导演使用本地随机种子、尝试次数、已获得成就、各路线尝试次数和最近结果调整候选结果权重。相同种子、完整状态和相同用户选择必须得到相同的下一结果。

首版硬约束参数固定如下；如需调整，应回到产品决策审核，而不是由内容权重静默覆盖：

| 参数 | 值 | 约束 |
| --- | ---: | --- |
| `maxConsecutiveSameOutcome` | 2 | 同一可重试结果连续上限 |
| `maxConsecutiveNoSuccess` | 3 | 成功可达选择的连续无成功上限 |
| `binaryRouteCoverageCap` | 3 | 同一黄牛成功/失败路线覆盖两个结果的选择上限 |
| `guidedCollectionCap` | 12 | 遵循提示时收齐七项成就的有效结果上限 |
| `hintAfterNoNewAchievement` | 2 | 连续无新成就后显示提示的阈值 |
| `maxNetworkErrorPerCycle` | 1 | 每个未过期收集周期的网络波动上限 |

软权重之外必须满足以下硬约束：

- 只在用户当前选择允许的结果中调整，不能替用户进入未选择的路线。
- 同一个可重试结果最多连续出现 2 次。
- 最多连续产生 3 个“本可产生成功结果但仍未成功”的有效结果；下一次用户选择成功可达路线时必须成功。
- 对原价黄牛和优惠黄牛两条成功/失败路线，用户持续选择同一路线时，最多 3 次有效选择必须覆盖该路线的两个结果。
- 用户遵循结果页提示并选择提示所指的可用路线时，最多 12 个有效结果必须获得全部 7 项成就。
- `ENDING_NETWORK_ERROR` 在一次未过期的收集周期内最多出现一次；用户清除状态或状态过期后开始新周期。
- 连续 2 个有效结果没有获得新成就后，结果页使用当前语言显示一条低干扰操作提示。提示只建议下一条可用路线，不公开隐藏结局名称、概率或导演规则。
- 全部成就获得后停止收集提示和覆盖性强制，恢复基础权重；仍保留防止相同结果和连续失败卡住体验的约束。

“有效结果”指上表七个 Outcome ID 之一被结算。正常渠道失败、打开报价、返回查看和其他中间步骤不计为有效结果。

## 本地状态

使用一个小型类型化状态层维护 `ticketExperienceState`，并以带版本号的 `localStorage` 保存。持久状态仅包含：

- `schemaVersion`；
- `rngSeed`；
- 唯一的 `achievementIds`；
- `attemptCount`；
- `routeAttemptCounts`；
- 为执行硬约束所需的有限 `recentOutcomeIds`；
- `updatedAt`；
- `expiresAt`。

状态采用 30 天滚动期限。只有结算有效结果、解锁成就或更新导演所需计数时才更新期限；浏览页面、打开提示或下载凭据不续期。过期状态按不存在处理，用户也可以一步清除。

不得持久保存完整场次、分区、价格表、SVG/PNG、翻译文案、订单或用户身份。当前 `performanceId`、分区和价格只属于本轮内存中的 `purchaseDraft`，刷新后可以由 URL 与内容记录重新选择。`localStorage` 不可用时退化为当前页面会话内存，不阻断购票体验。

稳定的成就 ID 在全部地域配置间共用；切换语言不会重复解锁成就，名称、提示和结果说明则始终使用当前语言。

## 七段组合印章与观演凭据

- 观演凭据使用一个原创的七图层 SVG 组合印章，每个唯一成就解锁一个固定 `stampSegmentId`。
- 重复结局不叠加图层；集齐七项后形成完整徽记。图形不得直接依赖中文“正”字等单一语言的阅读规则。
- 印章旁的图例、成就名称和状态使用当前地域配置语言；图形分段不能成为理解结果的唯一方式。
- 成功结果按生成当时的 `achievementIds` 渲染 SVG，并可以导出 SVG/PNG；后续成就不会修改用户已经下载的文件。
- 失败结果可以解锁成就，但不生成或下载观演凭据。下一次成功时，新凭据呈现届时已获得的全部唯一印章图层。
- 不生成 PDF、真实条码、商户字段或可用于现实入场的编码。

观演凭据的完整字段清单、七段图形造型、正式成就名称和各语言文案仍需人工审核；这些待定项不能改变本文件已经固定的流程、ID、状态和结果能力。

## 地域化术语门

- 内部模块 ID、状态键、Outcome ID 和 URL 保持稳定，不翻译成界面词汇。
- 每个地域配置启用购票体验前，内容人员必须检索并审核其现实语言和文化中演出购票网站常用的入口、购票、失败、重试、手续费和凭据相关词汇。
- 经审核词汇进入该地域配置的消息或内容资源，不写入 `docs/background`，也不从国家实体名称、现实语言标签或其他地域配置自动推断。
- 缺少已审核购票术语的地域配置不得启用购票模块；不使用炎国词汇或其他语言静默回退来伪装完成。

## 实现验证

- 以固定种子覆盖七个结局、两条成功/失败黄牛路线和全部导演硬约束。
- 验证遵循提示时 12 个有效结果内可以收齐七项成就，且任何结局都不会因权重调整永久不可达。
- 验证 30 天到期、滚动续期、显式清除、存储不可用降级和跨语言共用 ID。
- 验证成功与失败的双币金额、参数边界及最终舍入，且页面不产生现实支付或订单状态。
- 验证失败结果没有下载入口，成功凭据只包含唯一成就图层，重复结局不改变印章。
