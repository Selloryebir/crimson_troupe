# 架构：任务核心与可选沉浸层

```text
docs/background + docs/content（只读资料）
        │ 直接文件路径
        ▼
adapters → ContentRecord
        │
        ▼
M0 task shell（导航、日历、详情、到访、状态、无障碍）
        │ page slots
        ▼
optional modules（票篮、档案、i18n、小游戏、片场）
```

## M0 核心必须独立完成

- 搜索落地、任务型主导航、演出日历/筛选、演出详情、剧团、剧目、到访。
- 开售状态说明、可访问演出标签、稳定演出版、闭幕、低带宽和无 JavaScript。
- `/` 跳转 `/yan/`；核心页面使用 `/:profile/` 前缀并在 M0 只生成炎国配置。
- 五个主导航栏目承载七类页面与任务；剧目详情是所属栏目下钻路由，M0 不建立人物或场馆详情路由。

## 核心壳信息输入

核心壳直接读取以下资料；可插拔模块的输入只在各模块 YAML 中声明，旅程注册表不重复维护：

- `docs/background/02_crimson_troupe/03_phantom_and_crimson_solitaire/04_活页剧目.csv`
- `docs/content/01_world/04_巡演地点候选.csv`
- `docs/background/01_world/06_泰拉纪年.csv`
- `docs/background/03_terminology/01_核心专名.csv`
- `docs/background/03_terminology/90_reference_lexicon/01_泰拉词库.csv`

进入 M0 编码前，agent 另行生成示例草案并交由人工初审。通过后才建立 `docs/content/90_examples/01_m0/`；届时按职责把其中实际存在的文件补入本节核心输入或对应模块 YAML，不重复声明，也不在当前决策阶段创建空目录或预写不存在的文件路径。

沉浸层可以改变呈现和本地叙事状态，不能覆盖原文、夺走正常 CTA 或让用户必须玩游戏才能完成任务。所有模块只读取各自 `信息输入` 中声明的 `docs/` 文件，卸载时清理声音、定时器、Canvas、监听器和剧情 CSS。核心壳只保留地域配置解析、消息解析与格式化的稳定接入面；选择器、文本资源、格式规则和地域文案由 i18n 插件提供。

构建时先明确选择一个内容集，再由同一个类型化适配器读取 CSV、Markdown 和 YAML，校验后生成只读内容快照；示例集与人工编辑并启用的内容复用契约但不得自动合并，页面和模块不得人工复制为第二份前端 JSON。正式发布引用 `docs/content/90_examples/` 时必须失败。地域配置适配器必须校验 `id`、路径、HTML 语言、资源集、国家实体、世界内语言、货币和回退关系的完整性与唯一性。

搜索快照按 `localeProfileId` 分别生成，只包含当前配置获准公开的剧目、场次、成员、地点、专名和同语言别名。其他地域配置、其他语言字段和炎国回退文本不得进入当前索引；缺少必要搜索文本的记录只从该配置索引中排除，不影响直接链接按普通页面规则回退。维多利亚与哥伦比亚可以复用英语基础资源，但仍生成两个地域配置索引。

内容状态只读；体验状态默认本地；最小实现没有现实身份状态。分享链接使用当前地域配置的规范路径，只编码允许的筛选、剧透和虚构选择，不含设备标识或真实身份。
