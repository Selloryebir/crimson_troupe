# 架构：任务核心与可选沉浸层

```text
docs/background + docs/content（只读资料）
        │ 直接文件路径
        ▼
adapters → ContentRecord
        │
        ▼
M0 task shell（导航、日历、详情、到访、状态、无障碍）
        │ page slots
        ▼
optional modules（票篮、档案、i18n、小游戏、片场）
```

## M0 核心必须独立完成

- 搜索落地、任务型主导航、演出日历/筛选、演出详情、剧团、剧目、到访。
- 开售状态说明、可访问演出标签、稳定演出版、闭幕、低带宽和无 JavaScript。
- `/`、`/schedule`、`/schedule/:id`、`/troupe`、`/repertoire`、`/visit`、`/search`。

## 核心壳信息输入

核心壳直接读取以下资料；可插拔模块的输入只在各模块 YAML 中声明，旅程注册表不重复维护：

- `docs/background/02_crimson_troupe/03_phantom_and_crimson_solitaire/04_活页剧目.csv`
- `docs/content/01_world/04_巡演地点候选.csv`
- `docs/background/01_world/06_泰拉纪年.csv`
- `docs/background/03_terminology/01_核心专名.csv`
- `docs/background/03_terminology/90_reference_lexicon/01_泰拉词库.csv`

沉浸层可以改变呈现和本地叙事状态，不能覆盖原文、夺走正常 CTA 或让用户必须玩游戏才能完成任务。所有模块只读取各自 `信息输入` 中声明的 `docs/` 文件，卸载时清理声音、定时器、Canvas、监听器和剧情 CSS。

内容状态只读；体验状态默认本地；最小实现没有现实身份状态。分享链接只编码允许的语言、筛选、剧透和虚构选择，不含设备标识或真实身份。
