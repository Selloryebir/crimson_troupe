# 参考代码结构

```text
src/
  app/                         # 表网站地域路由壳：/:profile/…；/ 跳转 /yan/
  core/
    navigation/                # 任务型菜单、面包屑、持续票篮与闭幕入口
    content/                   # 经审核的 docs/content 内容集与只读适配器
    contracts/                 # ContentRecord、SiteEdition、Production、Performance、Venue、TicketState
    journeys/                  # 旅程 ID、路由守卫、恢复动作；不复制旅程文案
    i18n/                      # 地域配置、消息、格式化与回退的插件接入面
    narrative/                 # 稳定模式与叙事插件接入面；M0 不含历史网站状态机
    accessibility/             # 动效、声音、高对比、低带宽、无计时
    slots/                     # 声明式模块挂载点
  modules/                     # 每个可选模块独立目录；M3 历史网站拥有独立路由与页面
  content-generated/           # 构建产物；不手改
  components/
    dev-gallery/               # 仅开发环境使用的轻量组件展厅
  styles/tokens/
  tests/
    contracts/                 # schema 与输入路径校验
    journeys/                  # 每个 JRN 的 happy/recovery/keyboard 路径
    accessibility/
    narrative-state/
    visual/
public/
  assets/                       # 仅放项目原创或已取得必要授权的素材
  print/
scripts/
  ingest-docs.*
  validate-content.*
  validate-journeys.*
  generate-ticket.*
```

模块内部只暴露入口、路由、状态、内容适配器、降级组件和测试；不得导入其他模块内部文件。构建顺序是：选择一个经审核的 `docs/content` 内容集 → 校验 `contentSetId`、`siteEditionId`、`localeProfileId`、路由清单和自然定位字段 → 由类型化适配器生成只读内容快照 → 按 `localeProfileId + siteEditionId` 生成隔离搜索索引 → 校验地域配置、路由、插槽和依赖 → 跑当前批次旅程的主流程与恢复路径 → 验证 i18n 接入面 → 再启用其他地域配置与增强模块。构建器不得读取或索引 `docs/background`。

M0 编码前另设内容准备门：agent 先生成示例草案，人工初审后才建立 `docs/content/90_examples/01_m0/` 并允许 demo 构建读取。示例集与人工编辑并启用的内容共享契约和适配器，但一次构建只能选择一个内容集；正式发布引用示例目录时必须失败。当前决策修正文档时不创建示例数据。

轻量组件展厅复用正式组件、token 和经过初审的示例数据，只在开发环境与预览构建的受限入口中生成；不引入独立组件框架，也不进入正式导航或生产站点地图。

M0 只把 `siteEditionId = new-dionysus` 作为内容与搜索边界，不生成 M3 页面、切换器或异常状态机。M3 的历史网站模块使用独立路由清单和页面组件；只有语义确实相同的底层工具可以复用，不能要求表里网站拥有相同页面、记录数量或功能。
