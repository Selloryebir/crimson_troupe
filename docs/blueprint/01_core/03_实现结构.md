# 参考代码结构

```text
src/
  app/                         # 地域路由壳：/:profile/…；/ 跳转 /yan/
  core/
    navigation/                # 任务型菜单、面包屑、持续票篮与闭幕入口
    content/                   # docs 资料路径、CSV/Markdown/YAML 只读适配器
    contracts/                 # ContentRecord、Production、Performance、Venue、TicketState
    journeys/                  # 旅程 ID、路由守卫、恢复动作；不复制旅程文案
    i18n/                      # 地域配置、消息、格式化与回退的插件接入面
    narrative/                 # 稳定模式与叙事插件接入面；M0 不含时间层状态机
    accessibility/             # 动效、声音、高对比、低带宽、无计时
    slots/                     # 声明式模块挂载点
  modules/                     # 每个可选模块独立目录
  content-generated/           # 构建产物；不手改
  components/
    dev-gallery/               # 仅开发环境使用的轻量组件展厅
  styles/tokens/
  tests/
    contracts/                 # schema 与输入路径校验
    journeys/                  # 每个 JRN 的 happy/recovery/keyboard 路径
    accessibility/
    narrative-state/
    visual/
public/
  assets/                       # 仅放项目原创或已取得必要授权的素材
  print/
scripts/
  ingest-docs.*
  validate-content.*
  validate-journeys.*
  generate-ticket.*
```

模块内部只暴露入口、路由、状态、内容适配器、降级组件和测试；不得导入其他模块内部文件。构建顺序是：验证 CSV/Markdown/YAML 输入文件与自然定位字段 → 由类型化适配器生成只读内容快照 → 校验地域配置、路由、插槽和依赖 → 跑 M0 核心及每条基线旅程的恢复路径 → 验证 i18n 接入面 → 再启用其他地域配置与增强模块。

轻量组件展厅复用正式组件、token 和示例数据，只在开发环境与预览构建的受限入口中生成；不引入独立组件框架，也不进入正式导航或生产站点地图。
