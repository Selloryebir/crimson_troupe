# 内容边界

## 三层文案

| 层 | 内容 | 标记 |
| --- | --- | --- |
| 事实 | 客户端、官方资料或可回溯转录 | 来源、服务器、版本 |
| 编辑 | 对组织、历史、语言与体验的分析 | “编辑归纳/岗位推演” |
| 创作 | 官网公告、虚构场次、票样、小游戏、角色化文案 | “同人网站设定/非官方” |

三层可以同页出现，但不能共用一种视觉而让读者误判。剧情中的“伪造档案”仍要在元数据中保留真实层级。

## 时间边界

背景事实时间线、表网站公开时间线和里网站历史时间线分别维护。人物关系、组织状态、可访问城市和演出安排都必须带时间；任一网站叙述都不能覆盖 background。

- M0 使用新酒神时期的表网站，以明亮、现代、可信的常规剧团官网承载基本任务；这是同人创作层，不表示官方确认新剧团安全或完整正常运营。
- M3 实现旧酒神历史网站快照。它拥有独立内容集、路由清单、页面数量、功能与设计 token，可以与表网站公开历史产生有意冲突。
- 古堡搜救、罗德岛调查、蓝卡坞事件等其他叙事层不会因为旧网站已经确定而自动成为独立网站版本。
- 表里冲突保存为两条独立创作记录，通过事实自然定位字段或创作关联标识连接；不得把冲突合并成 background 的新事实。

## 交易与招募边界

- 单场次购票流程是世界观预约模拟，只呈现“在泰拉订票会看到什么、经历什么”。“购票成功/失败”可以作为世界内结局文案，但不得表达现实支付已完成；不用“支付成功、发票、余额、退款到账”等现实交易事实语汇，也不产生现实交易、订单、权益或服务关系。
- 成功路线可生成 SVG/PNG “观演凭据”；失败路线只保留不可下载的结果说明和成就。观演凭据只显示剧目、场次日期与时间、城市/场馆、分区、LMD 票面价、随机长条票纹和当前七段组合印章。票纹不采用现实条码制式，不承载订单、校验、追踪或入场语义；非官方性质由网站入口和页脚说明，不重复印刷在凭据上。
- 不实现全局票篮、多场次暂存、流程内换场、改签、退款或本地凭据档案；每次流程只绑定 URL 中的一个场次。
- 购票与结果页的模拟结算同时显示 LMD 与当前地域展示配置显式绑定的世界内币种；观演凭据只显示 LMD 票面价。汇率由人员硬编码；缺失时可用 1:1 演示占位，但必须标注“演示汇率/待人工审核”，不得写入背景事实层。
- “加入我们”是剧团栏目下的静态信息页，不提供试镜、报名、用户输入或本地草稿。
- 黄牛、平台讽刺、黑暗条款和多结局均可保留；购票流程同时提供清晰的拒绝、重试、返回和稳定呈现路径。

## 来源元数据与公开范围

background 可以继续保存服务器、版本和来源元数据，但公开网站不提供剧透范围选择、服务器建议值或内容锁，也不使用这些字段控制页面与历史快照访问。历史入口的低显著度属于探索设计，不是权限或剧透门槛。

## 解释、专名与回退

- 必要解释使用标题下小字、术语旁短注或用户主动展开的说明，文案保持剧团运营语气，不用脱离页面的“玩家教程”打断沉浸。
- 普通页面只显示当前地域配置中的专名，不在首次出现时自动展开中英日对照。
- 中英日官方字段、工作译和语言学推拟只在证据或编辑预览中并列，并保留来源与审查状态。
- 普通页面缺译字段回退炎国配置；公开页面低干扰标注“中文原文”，开发预览另标“待译”，不得自动机翻。
- 搜索是回退规则的明确例外：索引和结果只使用当前 `localeProfileId + siteEditionId` 的文本，不读取炎国回退、其他语言字段、其他网站版本或 background；缺少当前组合必要搜索文本的记录不进入索引。

## 示例内容边界

当前决策阶段不生成示例内容。进入 M0 编码前，agent 依据网站需求、内容表达、沉浸效果和 `docs/background/` 的事实边界生成草案；人工初审确认适合 demo 后，才写入 `docs/content/90_examples/01_m0/`。

- 示例集使用 3 个剧目、6 个场次、6～8 名成员和 3 个地点，覆盖关系、筛选差异与正常零结果。
- background 只提供人物、剧目、地点、组织、专名和时代边界等事实锚点；示例场次、日期、状态、抵达窗口、公告和运营文案仍属于创作层。
- background 只参与草案准备和人工审阅；网站构建、模块和公开搜索只读取通过初审后进入 `docs/content` 的内容集。
- 示例集与人工编辑并启用的内容复用字段结构，但构建不得自动合并两者。
- 两套 M0 风格板和关键页面线框必须读取同一批经初审示例内容，不为视觉候选复制或改写第二份内容。
- 正式发布不得引用示例目录；拟采用的示例须复制或重写到正式内容位置并再次人工确认，不能在原目录中直接改成正式内容。
