# 内容边界

## 三层文案

| 层 | 内容 | 标记 |
| --- | --- | --- |
| 事实 | 客户端、官方资料或可回溯转录 | 来源、服务器、版本 |
| 编辑 | 对组织、历史、语言与体验的分析 | “编辑归纳/岗位推演” |
| 创作 | 官网公告、虚构场次、票样、小游戏、角色化文案 | “同人网站设定/非官方” |

三层可以同页出现，但不能共用一种视觉而让读者误判。剧情中的“伪造档案”仍要在元数据中保留真实层级。

## 时间边界

旧团营业、古堡搜救、罗德岛调查、蓝卡坞事件和新酒神时期是不同快照。人物关系、组织状态、可访问城市和演出安排都必须带时间。最小验证采用新酒神时期的公开营业层，以现代、常规剧团官网的形态承载基本任务；这是创作层默认快照，不表示官方确认新剧团安全或完整正常运营。多时间层只在后期根据必要性与实现成本重新评估。

## 交易与招募边界

- 票篮是世界观预约模拟，只呈现“在泰拉订票会看到什么、经历什么”；不用“支付成功、发票、余额、退款到账”等现实交易事实语汇，也不产生现实交易、凭证、权益或服务关系。
- 成功路线可生成 SVG/PNG “观演凭据”；失败路线只保留不可下载的结果说明。观演凭据写明不可入场、不可兑付、无现实价值，且不生成真实条码、商户号或税务字段。
- 价格同时显示 LMD 与当前地域展示配置显式绑定的世界内币种。汇率由人员硬编码；缺失时可用 1:1 演示占位，但必须标注“演示汇率/待人工审核”，不得写入背景事实层。
- “加入我们”是虚构试镜，不收真实简历、联系方式、健康或感染信息。
- 黄牛、平台讽刺、黑暗条款和多结局均可保留；同时提供同等显著的取消、退出和稳定路线。

## 服务器与剧透

内容记录 `server_availability` 和 `spoiler_scope`。默认不以国际服/日服空缺否定简中事实；交付页面可根据用户选择隐藏尚未上线内容，但信息池仍保留完整来源。

## 解释、专名与回退

- 必要解释使用标题下小字、术语旁短注或用户主动展开的说明，文案保持剧团运营语气，不用脱离页面的“玩家教程”打断沉浸。
- 普通页面只显示当前地域配置中的专名，不在首次出现时自动展开中英日对照。
- 中英日官方字段、工作译和语言学推拟只在证据、档案或编辑预览中并列，并保留来源与审查状态。
- 普通页面缺译字段回退炎国配置；公开页面低干扰标注“中文原文”，开发预览另标“待译”，不得自动机翻。
- 搜索是回退规则的明确例外：索引和结果只使用当前地域配置文本，不读取炎国回退或其他语言字段；缺少当前配置必要搜索文本的记录不进入索引。

## 示例内容边界

当前决策阶段不生成示例内容。进入 M0 编码前，agent 依据网站需求、内容表达、沉浸效果和 `docs/background/` 的事实边界生成草案；人工初审确认适合 demo 后，才写入 `docs/content/90_examples/01_m0/`。

- 示例集使用 3 个剧目、6 个场次、6～8 名成员和 3 个地点，覆盖关系、筛选差异与正常零结果。
- background 只提供人物、剧目、地点、组织、专名和时代边界等事实锚点；示例场次、日期、状态、抵达窗口、公告和运营文案仍属于创作层。
- 示例集与人工编辑并启用的内容复用字段结构，但构建不得自动合并两者。
- 正式发布不得引用示例目录；拟采用的示例须复制或重写到正式内容位置并再次人工确认，不能在原目录中直接改成正式内容。
