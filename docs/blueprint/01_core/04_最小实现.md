# 最小实现（M0）

只实现这一层，也必须像一个可用的专业演出机构官网，而不是概念首页。

## 路由与页面

- `/`：今夜/近期演出、通知、任务型主导航。
- `/schedule`：列表/日历、筛选、结果计数、历史入口。
- `/schedule/:id`：日期、场馆、演职员、节目、时长、幕间、状态、其他日期。
- `/troupe`：组织、人物、部门和年代边界。
- `/repertoire`：剧目与公开节目说明。
- `/visit`：移动城市/场馆、抵达窗口、首次观演和可访问性。
- `/search`：中英日专名搜索与正常无结果恢复。

## 必须输入

- `docs/background/02_crimson_troupe/01_organization/01_组织与沿革.md`
- `docs/background/02_crimson_troupe/01_organization/02_人物.csv`
- `docs/background/02_crimson_troupe/03_phantom_and_crimson_solitaire/04_活页剧目.csv`
- `docs/content/01_world/04_巡演地点候选.csv`
- `docs/background/03_terminology/01_核心专名.csv`

## 验证阶段默认

- M0 使用新酒神时期的公开营业层，不实现旧团、古堡与多时间层切换。
- M0 只验证 i18n 插件接入面；架构确认可部署后，首个交付版本实现简中、English、日本語。
- 其他世界内语域只按人工白名单逐项启用，不因资料表中存在候选项而自动实施。
- 票篮、观演凭据、购票小游戏、黄牛支线、彩蛋、档案馆和深层叙事均为 M0 之后的功能元素插件。
- 主视觉使用语义化 DOM/CSS 与原创二维素材，不实现 WebGL 或其他 3D 特效。

首屏先可用，再启幕；默认无声；稳定演出版和闭幕随时可达。仅在安装深层内容插件后启用剧透状态，不为 M0 预建完整叙事状态机。
