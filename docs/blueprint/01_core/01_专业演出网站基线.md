# 专业演出网站基线与泰拉化信息架构

这份蓝图只提取成熟演出机构的任务模式，不复制其视觉、文案或交易实现。

## 已确认的产品口径

- 主要访问者是了解《明日方舟》和集成战略的玩家；陌生访客通过标题下小字、术语旁短注、展开说明等融入式方式获得必要解释，不设置脱离世界内网站的百科式教学层。
- 公开页面第一眼应当是可信的泰拉剧团官网；入口、页脚和观演凭据以低干扰方式说明这是非官方世界观互动。
- 公开文案使用中性的剧团运营口吻；角色只在署名公告、批注和已安装的功能元素中发声。
- 首屏保持简洁，正文按基础任务、补充设定、证据或批注逐层展开。

## 官方站观察

- Vienna Philharmonic 的演出日历支持日历、筛选和结果计数；详情页把日期、时间、场馆、指挥/独奏/乐团、节目、票务信息、其他日期、日历导出和打印放在同一任务链中。
- 其票务说明区分本团售票、其他主办方售票、退回票释放、订阅候补、高需求抽签与免票开放演出。关键不是每场都显示“购买”，而是状态对应正确行动。
- Royal Ballet and Opera 的 What's On 提供日期、筛选、列表/日历和活动类型；详情页先给日期、场馆、价格/操作、时长，再承接背景内容。
- RBO 把首次观演、到访、可访问演出与场馆可访问性做成独立入口；幕后参观、洞察、排练与工作坊和正式演出共享“发现活动”的信息架构。

## 建议主导航

| 主入口 | 正常任务 | 泰拉副标题/增强层 |
| --- | --- | --- |
| 今夜 | 近期演出、重要通知、继续任务 | 今夜启幕、可选时间层状态 |
| 演出日历 | 日期/城市/剧目/状态筛选 | 移动城市节点、抵达窗口 |
| 剧目 | 剧目简介、制作、其他日期 | 活页剧目正反面、留声典藏 |
| 剧团 | 机构、人物、部门、历史 | 旧团/调查/蓝卡坞时代快照 |
| 巡演与到访 | 场馆、首次观演、可访问性、变更 | 天灾改线、技艺限制、候场侧幕 |
| 档案馆 | 历史演出、藏品、时间线 | 宝盒、幻觉、红丝绒、版本冲突 |

M0 工具区只固定搜索与稳定演出版；地域配置、剧透范围和票篮在对应插件安装后注册。双生相是后期页面内“公开/幕后”呈现层，不取代任务型菜单。

## 演出详情首屏顺序

1. 剧目/制作名、场次日期时间、城市与场馆。
2. 开售状态和一个明确主操作。
3. 演职员、节目、预计时长、幕间和可访问标签。
4. 同剧其他日期、加入日历、打印和分享。
5. 节目说明、背景、过往演出与幕后档案。

详情末尾固定显示少量规则可解释的相关场次、剧目或成员；不使用随机推荐，也不为了增加卡片数量扩展无关关联。

世界观增强只能出现在这个任务骨架之上；闭幕、低带宽或无 JavaScript 时仍能完成前四项。
