# 专业演出网站基线与泰拉化信息架构

这份蓝图只提取成熟演出机构的任务模式，不复制其视觉、文案或交易实现。

## 已确认的产品口径

- 主要访问者是了解《明日方舟》和集成战略的玩家；陌生访客通过标题下小字、术语旁短注、展开说明等融入式方式获得必要解释，不设置脱离世界内网站的百科式教学层。
- 公开页面第一眼应当是可信的泰拉剧团官网；入口和页脚以低干扰方式说明这是非官方世界观互动。
- 公开文案使用中性的剧团运营口吻；角色只在署名公告、批注和已安装的功能元素中发声。
- 首屏保持简洁，正文按基础任务、补充设定、证据或批注逐层展开。
- M0 保留七类公开页面与任务，但只设置五个主导航栏目；演出详情是下钻页面，搜索是工具。
- 手机与电脑承载相同任务；先建立手机纵向阅读流，再扩展电脑的舞台式排版。
- M0 使用明亮、现代、可信的新酒神表网站；旧酒神历史网站作为独立 M3 体验，不是 M0 换肤。

## 官方站观察

- Vienna Philharmonic 的演出日历支持日历、筛选和结果计数；详情页把日期、时间、场馆、指挥/独奏/乐团、节目、票务信息、其他日期、日历导出和打印放在同一任务链中。
- 其票务说明区分本团售票、其他主办方售票、退回票释放、订阅候补、高需求抽签与免票开放演出。关键不是每场都显示“购买”，而是状态对应正确行动。
- Royal Ballet and Opera 的 What's On 提供日期、筛选、列表/日历和活动类型；详情页先给日期、场馆、价格/操作、时长，再承接背景内容。
- RBO 把首次观演、到访、可访问演出与场馆可访问性做成独立入口；幕后参观、洞察、排练与工作坊和正式演出共享“发现活动”的信息架构。

## M0 主导航

| 主入口 | 正常任务 | 泰拉副标题/增强层 |
| --- | --- | --- |
| 今夜 | 近期演出、重要通知、继续任务 | 今夜启幕、当前网站版本戳 |
| 演出日历 | 未来列表、月历、剧目/城市/状态/可访问形式筛选 | 移动城市节点、抵达窗口 |
| 剧目 | 剧目简介、制作、其他日期 | 活页剧目正反面、留声典藏 |
| 剧团 | 机构、当前组织、人物、部门、时间边界 | 表网站公开历史；M3 另设旧网站快照 |
| 巡演与到访 | 场馆、首次观演、可访问性、变更 | 天灾改线、技艺限制、候场侧幕 |

首页按“主视觉与近期演出 → 公告 → 推荐剧目 → 剧团简介 → 到访提示”展开，首要行动是从今夜或近期演出进入详情。M0 工具区只固定搜索与稳定演出版；地域配置选择器在 i18n 插件安装后注册，购票入口则只在可购票场次的卡片与详情中出现，不进入全局导航。M3 旧网站快照拥有独立页面与导航，不作为表网站页面内的公开/幕后切换层。

七类页面与任务包括首页、演出日历、演出详情、剧目、剧团、巡演与到访、搜索。剧目允许列表与详情两个路由；M0 的人物和三个示例地点在所属栏目页内展示，不建立人物详情或场馆详情路由。页面类别不等于路由数量。

## 演出发现

- 演出日历默认显示未来场次列表，并允许切换月历；手机始终先显示列表。
- 首批筛选只有剧目、城市、场次状态和可访问形式。日期由列表与月历控制，不重复建立筛选组。
- 普通页面使用世界内日期；服务器发布日期只在用户主动查看的资料证据区单列。

## 演出详情首屏顺序

1. 剧目/制作名、场次日期时间、城市与场馆。
2. 开售状态和一个明确主操作；M0 用于查看场次状态或预约说明，购票模块安装后才替换为当前地域配置已经审核的购票操作名称。
3. 演职员、节目、预计时长、幕间和可访问标签。
4. 同剧其他日期、加入日历、打印和分享。
5. 节目说明、背景、过往演出与相关剧务内容。

详情末尾固定显示少量规则可解释的相关场次、剧目或成员；不使用随机推荐，也不为了增加卡片数量扩展无关关联。

世界观增强只能出现在这个任务骨架之上；稳定演出版、低带宽或无 JavaScript 时仍能完成前四项。只有安装并打开叙事叠层时才显示关闭该叠层的“闭幕”操作，历史网站则使用捕获栏和浏览器后退返回当前网站。

## 搜索边界

搜索只读取当前 `localeProfileId + siteEditionId` 的剧目、场次、成员、地点、获准公开的专名和同语言别名。索引、结果、摘要、纠错和无结果提示均不得读取其他地域配置、其他语言字段、炎国回退文本、其他网站版本或 background；缺少当前组合必要搜索文本的记录不进入索引。跨语言或跨版本对照只在用户主动进入证据或编辑预览后出现。M0 只生成 `yan + new-dionysus`。

## 错误、无结果与空状态

三类状态使用同一顺序：先以当前地域配置的语言说明发生了什么、可判断的原因和下一步操作，再附当前网站版本的沉浸文案。

- 错误状态：请求或模块未能完成，首要提供重试、返回或继续使用未受影响内容的操作。
- 无结果状态：搜索或筛选执行成功但没有匹配项，首要提供清除筛选、修改关键词或返回目录的操作。
- 空状态：当前栏目尚无记录或用户尚未建立本地内容，说明怎样产生内容；没有可执行动作时如实说明，而不显示无功能按钮。

表网站使用可信的剧团运营语气；里网站可以更阴暗，但不得用谜语、异常动效或角色提示替代原因、恢复操作和真实 HTTP 状态。Miss.Christine 不承担核心错误恢复。
