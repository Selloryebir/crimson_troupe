# 设计系统

## 核心气质

公开层是高卢旧地的巡演剧团：装订节目册、票券、旧报章、黄铜编号、帷幕与聚光。不要套通用哥特、马戏或故障艺术模板。异常来自“舞台侵入现实、档案被改写、角色替代人”，不是随机 glitch。

起始 token（同人设计建议，不是官方品牌规范）：

```css
:root {
  --stage-black: #0b090b;
  --curtain-red: #6f0d1b;
  --diamond-red: #b51632;
  --paper: #e7ddc8;
  --brass: #9b7843;
  --cold-blue: #4c78a8;
  --bruise-violet: #493657;
}
```

## 三层视觉

- 营业层：对称、克制、可信，留足纸面阅读空间。
- 古堡残响：缺席位、暗道编号、版本脚注、剪票孔和错装页。
- 新酒神：偏轴构图、冷蓝破幕、保留/重写旧版的可见痕迹。

## 动效词汇

允许：开合帷幕、聚光移动、纸页翻动、改稿划线、唱针、偶人丝线、低密度舞台粉尘。每个效果必须有静态降级；异常不覆盖原始证据文本。

避免：高频闪烁、全站噪声抖动、强制晕动、无法停止的滚动、突然自动播放、用故障效果代替信息层级。

## 响应式

- 桌面：节目栏 + 可选侧边增强；档案可双栏对照。
- 手机：单列纵向内容、底部票篮、分区席位卡、明确按钮翻页。
- 小屏不缩小桌面座位图；图谱必须有等价列表。
- 低带宽模式保留正文、剧目、观演提示、结局与纪念票文字版。

## 无障碍是世界观内的“稳定演出版”

- 声音默认关闭，主动开启后仍有全局停止。
- 拖拽有按钮替代，计时有无计时模式，Canvas 有文本视图。
- “闭幕”立即停止声音、动画和页面污染，返回稳定首页；不能做假按钮或反转。
- 证据级别同时用文字/图形，不只用色彩。
- 惊悚、自伤、感染与精神影响内容可以做提示和分级，但不强制替人员做内容取舍。

## 图像与权利轨道

资料包中的游戏图像用于研究和内部策划。公开站优先原创构图、原创票样与原创图标；官方图、音乐、字体、商标、域名和“是否可能被误认作官方站”均由人工在发布前做权利与风险评估。风险提示不替代创作决策。
