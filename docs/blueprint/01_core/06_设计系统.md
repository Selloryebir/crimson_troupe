# 设计系统

## 核心气质

公开层采用新酒神时期中最现代、最接近常规剧团营业状态的一面：装订节目册、观演凭据、报章、黄铜编号、帷幕与聚光。不要套通用哥特、马戏或故障艺术模板。异常来自“舞台侵入现实、档案被改写、角色替代人”，不是随机 glitch；M0 不实现异常时间层。

起始 token（同人设计建议，不是官方品牌规范）：

```css
:root {
  --stage-black: #0b090b;
  --curtain-red: #6f0d1b;
  --diamond-red: #b51632;
  --paper: #e7ddc8;
  --brass: #9b7843;
  --cold-blue: #4c78a8;
  --bruise-violet: #493657;
}
```

## 可扩展视觉层

- 新酒神公开营业层：M0 默认；对称、克制、可信，留足纸面阅读空间。
- 旧团与古堡残响：后期候选；缺席位、暗道编号、版本脚注、剪票孔和错装页。
- 新酒神异常层：后期候选；偏轴构图、冷蓝破幕、保留/重写旧版的可见痕迹。

地域配置可以覆盖字体、排版细节、日期格式、少量节目册结构和局部装饰，但不能另建组件体系或改变核心任务顺序。字体方案必须覆盖汉字、假名、拉丁字母、西里尔字母、希腊字母和波兰语附加字符；缺少对应字库时使用可读的系统字体回退。

## 动效词汇

允许：开合帷幕、聚光移动、纸页翻动、改稿划线、唱针、偶人丝线、低密度舞台粉尘。每个效果必须有静态降级；异常不覆盖原始证据文本。

避免：高频闪烁、全站噪声抖动、强制晕动、无法停止的滚动、突然自动播放、用故障效果代替信息层级。

## 响应式

- 桌面：节目栏 + 可选侧边增强；档案可双栏对照；安装票务插件后显示完整分区图。
- 手机：单列纵向内容；安装票务插件后仍显示完整分区图，不改成仅有分区卡片的替代界面。
- 席位只选择 S/A/B/C/D/包厢等分区，不选择具体座位；颜色必须同时配合文字、边界或纹理，并提供等价列表。
- 低带宽模式保留正文、剧目、观演提示、结局与观演凭据文字版。

## 无障碍是世界观内的“稳定演出版”

- 声音默认关闭，主动开启后仍有全局停止。
- 拖拽有按钮替代，计时有无计时模式，Canvas 有文本视图。
- “闭幕”立即停止声音、动画和页面污染，返回稳定首页；不能做假按钮或反转。
- 证据级别同时用文字/图形，不只用色彩。
- 惊悚、自伤、感染与精神影响内容可以做提示和分级，但不强制替人员做内容取舍。

## 图像与权利轨道

信息库不保存或索引游戏原图。公开站优先原创构图、原创票样与原创图标；官方图、音乐、字体、商标、域名和“是否可能被误认作官方站”均由人工在发布前做权利与风险评估。风险提示不替代创作决策。

## 组件预览

开发环境提供轻量组件展厅，直接展示正式按钮、卡片、提示、地域切换、票面和状态组件。展厅只复用生产组件与示例数据，不引入 Storybook 等独立工具，也不为预览维护第二套样式。
