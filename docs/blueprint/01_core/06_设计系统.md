# 设计系统

## 核心气质

M0 表网站采用新酒神时期中明亮、现代、可信、最接近常规剧团营业状态的一面：装订节目册、观演凭据、报章、黄铜编号、帷幕与聚光。保留猩红剧团的舞台主体，但不以诡异、惊悚或污染特效作为 M0 气质。M3 里网站才承载“舞台侵入现实、档案被改写、角色替代人”等 creepypasta 类表达；它不是随机 glitch，也不是表网站换肤。

起始 token（同人设计建议，不是官方品牌规范）：

```css
:root {
  --stage-black: #0b090b;
  --curtain-red: #6f0d1b;
  --diamond-red: #b51632;
  --paper: #e7ddc8;
  --brass: #9b7843;
  --cold-blue: #4c78a8;
  --bruise-violet: #493657;
}
```

M0 以 `--paper` 作为主要页面与连续阅读表面，深红、舞台黑和黄铜用于帷幕、标题、边框及局部强调，不能把正文包进持续压暗的恐怖界面。M3 里网站可以重新定义表面明度和异常层级，但不得反向改变表网站 token 的语义。

## 可扩展视觉层

- 新酒神表网站：M0 默认；明亮、现代、可信，留足纸面阅读空间。
- 旧酒神历史网站：M3 独立实现；可以使用涂黑字符、划改、撤回公告、被叉除的人物图、灾难新闻、错装页与异常动效，拥有独立 token、组件和页面结构。
- 古堡残响、罗德岛调查等其他叙事层：仍是未决定候选，不因 M3 旧网站确定而自动成为网站版本。
- 新酒神异常层：后期候选；偏轴构图、冷蓝破幕、保留/重写旧版的可见痕迹。

地域配置可以覆盖字体、排版细节、日期格式、少量节目册结构和局部装饰，但不能改变同一网站版本的核心任务顺序。表网站和里网站可以使用不同组件体系与页面数量；它们只复用语义确实一致的底层工具。字体方案必须覆盖汉字、假名、拉丁字母、西里尔字母、希腊字母和波兰语附加字符；缺少对应字库时使用可读的系统字体回退。

## 历史网站异常层级

M3 里网站使用四段可区分的视觉层级，而不在每次访问时随机生成强度。有效探索数、阈值和重置语义以 `docs/content/05_site_editions/README.md` 为唯一内容契约。

- 基线：保持可信的旧网站排版，只显示内容集预置的少量冲突。
- 低强度：使用局部划改、纸面偏移或不稳定批注，但不改变任务顺序。
- 增强：逐步增加涂抹、错装页、被划除人物和新闻冲突，始终保留可读原始内容。
- 饱和：维持经设计的最高异常水平，继续探索不再增加强度或叠加新特效。

稳定演出版隐藏后三段的渐进呈现，但不删除基线中已审核的冲突记录，也不重置本次访问进度。任何层级都不得遮挡捕获栏、返回当前网站、稳定演出版和错误恢复操作。

## 动效词汇

允许：开合帷幕、聚光移动、纸页翻动、改稿划线、唱针、偶人丝线、低密度舞台粉尘。每个效果必须有静态降级；异常不覆盖原始证据文本。

避免：高频闪烁、全站噪声抖动、强制晕动、无法停止的滚动、突然自动播放、用故障效果代替信息层级。

## 响应式

- 桌面：节目栏 + 可选侧边增强；档案可双栏对照；安装票务插件后显示完整分区图。
- 手机：单列纵向内容；安装票务插件后仍显示完整分区图，不改成仅有分区卡片的替代界面。
- 席位只选择 S/A/B/C/D/包厢等分区，不选择具体座位；颜色必须同时配合文字、边界或纹理，并提供等价列表。
- 低带宽模式保留正文、剧目、观演提示、结局与观演凭据文字版。

## 无障碍是世界观内的“稳定演出版”

- 声音默认关闭，主动开启后仍有全局停止。
- 拖拽有按钮替代，计时有无计时模式，Canvas 有文本视图。
- “闭幕”立即停止声音、动画和页面污染，返回稳定首页；不能做假按钮或反转。
- 证据级别同时用文字/图形，不只用色彩。
- 惊悚、自伤、感染与精神影响内容可以做提示和分级，但不强制替人员做内容取舍。

## 图像与权利轨道

信息库不保存或索引游戏原图。公开站优先原创构图、原创票样与原创图标；官方图、音乐、字体、商标、域名和“是否可能被误认作官方站”均由人工在发布前做权利与风险评估。风险提示不替代创作决策。

## 组件预览

开发环境提供轻量组件展厅，直接展示正式按钮、卡片、提示、地域切换、票面和状态组件。展厅只复用生产组件与经人工初审后进入独立数据集的示例内容，不引入 Storybook 等独立工具，也不为预览维护第二套样式。
