# 技术 i18n

本目录只描述网站运行时的国际化实现。

- `01_locales.yaml`：语言选择器标签、文本方向、回退、字体、语音和缓存键。
- `02_旧标签映射.csv`：旧内容项目标签到规范运行时标签的迁移映射。

官方中英日专名见 `../../background/03_terminology/`；创意内容的工作译和泰拉语域方案见 `../../content/03_localization/`。

虚构语言标签使用 RFC 5646 private-use 形式，例如 `x-ak-siracusa`。这些标签只用于项目内部路由，不是 ISO 或 IANA 已注册语言。页面语言与泰拉语域是两套独立选择器，不能共用状态字段。

## 实施阶段

- M0 只验证语言标签、消息解析和格式化的插件接入面，不交付完整语言选择器。
- 架构确认可部署后，首个交付版本实现简中、English、日本語。
- 世界内语域只按人工白名单逐项启用，不默认实施 `01_locales.yaml` 中的所有候选项。
- 页面语言、世界内语域、地区实体和货币必须显式映射，不根据名称或标签自动推断。
