# 技术 i18n 与地域展示配置

本目录只描述网站运行时的国际化实现。`01_locales.yaml` 是地域展示配置的唯一技术清单；它把一个人工批准的国家实体、现实文本语言、世界内语言身份、URL、货币、字体覆盖、资源集和回退关系绑定为同一个切换单元。

官方中英日专名见 `../../background/03_terminology/`，只用于人工和 agent 准备内容；构建所需专名必须经过审核后进入 `../../content/` 内容集。创意内容的工作译、语言学研究和未实施候选见 `../../content/03_localization/`。

## 标识边界

- `id` 是项目内部地域配置标识。
- `路径` 是沉浸式国家实体 URL，不是现实语言代码。
- `HTML语言` 只描述页面实际文字，使用有效的 BCP 47 标签。
- `世界内语言` 是泰拉叙事身份，不充当 HTML 标签或路由缩写。
- 货币通过地域配置显式关联，不从语言、国家名称或 URL 猜测。
- `配置名称` 只帮助维护者辨识条目；面向用户的选择器文案从 `background` 官方专名或 `content` 工作译读取，不在蓝图中复制。

项目尚未发布旧 URL、持久化用户数据或兼容 API，因此不维护旧标签迁移层，也不继续使用旧 private-use 语言标签。普通页面只有一个地域配置选择器和一个 `localeProfileId` 状态；证据对照是否开启是独立的编辑预览状态，不构成第二套语言选择。

## 实施阶段

- M0 只生成炎国配置并验证地域配置、消息解析和格式化的插件接入面；`/` 跳转到 `/yan/`。
- 架构确认可部署后，首个多语言版本交付炎国、东国、维多利亚和哥伦比亚四个配置；四者必须覆盖全部 M0 页面并通过同一验收后共同发布。
- 首个多语言交付的必要正文不得依赖炎国回退补齐；普通页面回退只处理允许暂缺的非必要字段，搜索继续完全禁用该回退。
- 莱塔尼亚是后续六个已批准配置中的第一优先，用于验证德语排版和 LED 演示占位；它仍在 M2 黄牛支线与七结局导演完成后开始，不改变既定批次。
- 叙拉古、米诺斯、乌萨斯、卡西米尔和拉特兰继续列入后续计划，彼此顺序由人工另行安排。
- 其他研究候选不进入运行时清单；新增配置必须由人工批准并完整补齐路径、HTML 语言、资源、货币和回退关系。
- 维多利亚与哥伦比亚共享英语基础资源，分别覆盖 `en-GB` 与 `en-US` 的拼写、格式、术语和地域文案。

## 购票术语启用门

- `purchase_flow`、状态键、Outcome ID 和 URL 是稳定技术标识，不作为界面词翻译。
- 每个地域配置启用购票模块前，内容人员必须检索并审核相应现实语言和文化中的演出购票网站常用词汇，至少覆盖入口、购票、失败、重试、加价、手续费、优惠和凭据。
- 审核后的显示词进入该地域配置的消息或内容资源；“票篮”只作为旧讨论简称，不预设为任何语言的正式用词。
- 缺少已审核购票术语时，该地域配置不得启用购票模块，也不得静默回退炎国或其他地域的购票词汇。普通内容的既有回退规则不因此改变。

## 搜索隔离

- 每个 `localeProfileId + siteEditionId` 独立生成搜索索引；语言标签相同或页面主题相近也不能合并地域或网站版本索引。
- background 不进入公开搜索；表网站和历史网站分别使用当前内容集获准公开的专名、同语言别名和正文。
- 只索引当前组合中获准公开的剧目、场次、成员、地点、专名和同语言别名。
- 查询、结果、摘要、纠错和无结果提示不得读取其他地域配置、其他语言字段、炎国回退文本、其他网站版本或 background。
- 缺少当前组合必要搜索文本的记录不进入该索引，但直接访问其页面时仍可按普通页面规则回退炎国并标注“中文原文”。
- 搜索结果可以提供使用当前配置语言书写的证据入口；只有用户主动进入证据或编辑预览后才显示跨语言对照。
- 维多利亚与哥伦比亚可以共享英语基础资源，但必须分别应用 `en-GB`、`en-US` 覆盖和地域文案后生成索引。

## 路由与收录

- `/` 只跳转到 `/yan/`；每个已启用配置在自己的国家实体路径下生成同构页面。
- canonical 使用当前地域配置的完整路径；`hreflang` 使用 `HTML语言`，不使用配置 id 或路径 slug。
- 未启用、缺少必要资源或仍为研究候选的配置不生成公开页面、站点地图或 `hreflang` 条目。
- 预览环境保持禁止搜索引擎收录；正式域名、站点地图和收录条件由 [发布与维护](../01_core/07_发布与维护.md#正式域名与搜索引擎收录) 统一规定。
