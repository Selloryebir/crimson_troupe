# 技术 i18n 与地域展示配置

本目录只描述网站运行时的国际化实现。`01_locales.yaml` 是地域展示配置的唯一技术清单；它把一个人工批准的国家实体、现实文本语言、世界内语言身份、URL、货币、字体覆盖、资源集和回退关系绑定为同一个切换单元。

官方中英日专名见 `../../background/03_terminology/`；创意内容的工作译、语言学研究和未实施候选见 `../../content/03_localization/`。

## 标识边界

- `id` 是项目内部地域配置标识。
- `路径` 是沉浸式国家实体 URL，不是现实语言代码。
- `HTML语言` 只描述页面实际文字，使用有效的 BCP 47 标签。
- `世界内语言` 是泰拉叙事身份，不充当 HTML 标签或路由缩写。
- 货币通过地域配置显式关联，不从语言、国家名称或 URL 猜测。
- `配置名称` 只帮助维护者辨识条目；面向用户的选择器文案从 `background` 官方专名或 `content` 工作译读取，不在蓝图中复制。

项目尚未发布旧 URL、持久化用户数据或兼容 API，因此不维护旧标签迁移层，也不继续使用旧 private-use 语言标签。普通页面只有一个地域配置选择器和一个 `localeProfileId` 状态；证据对照是否开启是独立的编辑/档案状态，不构成第二套语言选择。

## 实施阶段

- M0 只生成炎国配置并验证地域配置、消息解析和格式化的插件接入面；`/` 跳转到 `/yan/`。
- 架构确认可部署后，首个多语言版本交付炎国、东国、维多利亚和哥伦比亚四个配置。
- 叙拉古、米诺斯、乌萨斯、卡西米尔、莱塔尼亚和拉特兰已进入后续计划，但启用顺序仍按阶段人工安排。
- 其他研究候选不进入运行时清单；新增配置必须由人工批准并完整补齐路径、HTML 语言、资源、货币和回退关系。
- 维多利亚与哥伦比亚共享英语基础资源，分别覆盖 `en-GB` 与 `en-US` 的拼写、格式、术语和地域文案。

## 搜索隔离

- 每个 `localeProfileId` 独立生成搜索索引；语言标签相同也不能合并索引。
- 只索引当前配置中获准公开的剧目、场次、成员、地点、专名和同语言别名。
- 查询、结果、摘要、纠错和无结果提示不得读取其他配置、其他语言字段或炎国回退文本。
- 缺少当前配置必要搜索文本的记录不进入该索引，但直接访问其页面时仍可按普通页面规则回退炎国并标注“中文原文”。
- 搜索结果可以提供使用当前配置语言书写的证据入口；只有用户主动进入证据、档案或编辑预览后才显示跨语言对照。
- 维多利亚与哥伦比亚可以共享英语基础资源，但必须分别应用 `en-GB`、`en-US` 覆盖和地域文案后生成索引。

## 路由与收录

- `/` 只跳转到 `/yan/`；每个已启用配置在自己的国家实体路径下生成同构页面。
- canonical 使用当前地域配置的完整路径；`hreflang` 使用 `HTML语言`，不使用配置 id 或路径 slug。
- 未启用、缺少必要资源或仍为研究候选的配置不生成公开页面、站点地图或 `hreflang` 条目。
- 预览环境保持禁止搜索引擎收录；正式收录仍按发布决策单独批准。
