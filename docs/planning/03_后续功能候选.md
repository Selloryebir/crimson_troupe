# 后续功能候选

本文件保存尚未获准进入开发路线、但仍有独立创作价值的功能设想。候选项不是蓝图模块、用户旅程或实现承诺；只有人工另行批准后，才能重新建立模块、路由、状态和开发批次。

候选内容不得依赖已经取消的通用档案馆、持续活动、声音播放或按结局重排表网站。重新评估时应先说明它服务的页面任务，再决定是否需要独立模块。

## 明确不再保留的方案

- 四周或每日更新的线上活动、赛季进度、真实或虚构倒计时。
- 活动结束后切换 `archive_mode`、把活动整体转入档案馆或建立重演状态。
- 依赖通用档案馆承载藏品、结局、新闻、时间线、声音和全部后续互动。
- 根据购票或剧情结局改变表网站内容记录、页面顺序、导航或搜索。
- 网站音频播放、播放器、音量偏好、Web Audio、原创声景和授权后接入音源。
- 试镜问答、舞台名生成、改写报名表、招募输入和本地加入结局。
