# 资料审核

本目录集中保存资料治理信息，供人工复核与后续补全使用。

| 文件 | 用途 |
|---|---|
| `01_证据与审核规范.md` | 证据级别、三服核对顺序与展示规则 |
| `02_来源登记.csv` | 来源 URL 的渠道、服务范围、证据级别与复核日期 |
| `03_待审核事项.csv` | 尚待裁定、检索或持续跟踪的问题 |
| `04_覆盖与缺口.md` | 当前资料覆盖范围、明确边界和优先补全方向 |

来源登记用于描述入口本身，不替代各事实记录中的“来源”“依据”“确定性”等逐条证据字段。待审核事项的人工结论应填写在保留列中；结论影响事实或内容时，还须同步回填其唯一维护文件。
