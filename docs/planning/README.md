# 项目规划与资料治理

本目录保存跨越事实、内容与实现三层的审核制度、来源登记、待办事项、覆盖评估和决策收集。它回答“资料如何复核、目前缺什么、下一步先处理什么、开发前还需要决定什么”，不承载世界观事实正文、创作方案或网站技术实现。

| 目录或文件 | 内容 |
| --- | --- |
| `01_knowledge_review/` | 证据分级、来源登记、待审核事项和覆盖缺口 |
| `02_网站产品与实现决策问卷.md` | 预开发阶段的产品、体验、素材、技术和运营选择题 |

维护时应把审核结论回填到事实或内容的唯一维护位置；本目录记录审核过程和跨领域工作项，不复制完整事实表。
