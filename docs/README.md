# 猩红剧团项目文档

本目录是项目的主要信息库。文档按“背景事实、创作应用、工程实现、规划治理”分层；文内仓库路径均以 `docs/` 为根。

| 目录 | 回答的问题 | 内容边界 |
| --- | --- | --- |
| `background/` | 《明日方舟》世界中什么为真、什么尚未确定 | 世界观事实、事实边界、官方中英日专名和公开来源索引 |
| `content/` | 这些事实如何转化为网站内容 | 编辑推演、创作口径、工作译、内容本地化，以及与人工启用内容隔离的 demo 示例集 |
| `blueprint/` | 网站具体怎样设计、开发和部署 | 架构、功能、模块、用户旅程、结构契约和技术 i18n |
| `planning/` | 资料与项目下一步怎样复核和推进 | 来源登记、证据规范、审核事项、覆盖缺口与预开发决策收集 |

组织、命名、格式与唯一来源规则见 `01_文档组织规范.md`。
